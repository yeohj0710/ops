# 계정 지도

> **어디에 어떤 아이디로 로그인돼 있는지**만 적는다. 비밀번호는 적지 않는다.
> 에이전트는 이 표를 보고 "그 일은 어느 브라우저 프로필로 하면 되는지"를 안다.

## 왜 비밀번호를 안 적나

에이전트는 로그인 창에 비밀번호를 대신 쳐 넣지 않는다. 대신 **사람이 이미 로그인해 둔
크롬 세션(L3)** 을 그대로 쓴다. 그게 더 빠르고, 비밀번호가 어디에도 안 남는다.
세션이 풀렸으면 사람이 한 번 로그인해 주면 그때부터 다시 알아서 쓴다.

## 세션이 풀렸을 때

에이전트가 로그인 화면을 만나면 **거기서 멈추고 사람에게 알린다.**
비밀번호를 찾아 넣으려 하지 않는다. 사람이 브라우저에서 한 번 로그인하면 이어서 진행한다.
