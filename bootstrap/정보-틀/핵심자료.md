# 회사 서류·자산 어디 있나

원본은 전부 여기 있다. **복사본을 만들지 마라** — 서류가 갈라지면 어느 게 최신인지 모른다.

```
G:\내 드라이브\여형준님\00 핵심 자료\
```

컴마다 드라이브 문자가 다르면 `내 드라이브\여형준님\00 핵심 자료` 로 찾는다.
아래 경로는 그 폴더 기준 상대경로다.

## 손대면 안 되는 것

- **`제출용 서류/권혁찬 주민등록번호.txt`** — 주민등록번호. 옮기지도, 화면에 찍지도, 어디에도 붙여넣지 마라.
  주민번호가 필요한 서식을 만나면 사람을 부른다.
- **`제출용 서류/NPKI/`** — 공동인증서. 건드리지 마라.
- 법인 통장사본·인감증명서는 **요청한 곳에만** 낸다. 보내기 전에 사람에게 확인받는다.

## 폴더 구분

| 폴더 | 무엇 |
| --- | --- |
| `제출용 서류/` | **지금 쓰는 것.** 여기부터 본다 |
| `회사 소개 자료/` | 사업계획서·IR·브로슈어 |
| `(구) 주요 서류/` | 옛 사본. 제출용에 없을 때만 본다 (사업자등록증이 그렇다) |
| `etc/` | 4대보험 명부, 법인등기부 이미지 |

같은 서류가 여러 폴더에 있으면 **`제출용 서류/` 것이 최신이다.**
날짜가 붙은 파일은 뒤 숫자가 큰 게 최신이다.
