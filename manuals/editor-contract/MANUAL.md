# 편집자 업무위탁계약서 작성

- **부르는 말**: 편집자 계약서 만들어줘, 편집자님 계약서 새로 써줘, 영상편집 업무위탁계약서, 프리랜서 편집자 계약서, 편집자 계약서 다시 써줘
- **미리 허가**: 드라이브 편집자님 계약서 폴더에 docx와 pdf 저장, 작업 기록 폴더 생성. 계약서를 편집자에게 보내는 것은 하지 않는다
- **런너**: claude
- **제어층**: L1
- **한 번에 걸리는 시간**: 30~40분

`<드라이브>` 는 `<OPS>/machine.json` 의 `drive_root` 다. 보통 `G:/내 드라이브`.

---

## 무엇을 만드는 업무인가

새로 뽑은 영상 편집자와 맺을 업무위탁계약서를 docx와 pdf로 만든다. 끝나면 이것이 있어야 한다.

- `<드라이브>/영상 편집/[공통] 유용한 소스/편집자님 계약서/영상편집_업무위탁계약서_<성명>님.docx` 와 같은 이름의 `.pdf`
- 같은 폴더 `etc/<성명>_계약서_작업/` 에 생성 스크립트와 `artifact.md` (바탕 자료, 공고에서 바뀐 조건, 정한 값, 빈칸)

## 실행 계약

사용자가 이 업무를 호출하면 이 매뉴얼의 절차와 완료 검사를 한 번에 실행한다.
조건 모으기에서 멈추지 않고 파일 저장과 보고까지 간다. 계약서를 편집자에게 보내는 것만 사람이 한다.

## 준비물

- 편집자 성명, 합의한 편당 단가, 맡길 계정과 언어판 여부, 편집자가 말한 주당 가능 편수
- 공고 본문: `<드라이브>/여형준님/99 etc/01 마케팅/편집자 채용/` 의 공고 md
- 합의 기록: 지원 메일과 테스트 메일(메일 커넥터), 카톡 합의(사람이 붙여 준 대화나 `<DEV>/kakao-inbox`)

## 절차

1. **조건을 모은다 (L1)**
   공고 md 에서 기본 조건(정산일, 원천징수, 영상 길이)을 읽는다. 메일과 카톡에서 바뀐 조건(단가, 언어판, 주당 편수,
   연락 수단, 납품물)을 찾는다. 공고와 다른 값은 `artifact.md` 에 표로 적는다.

2. **사업자 여부를 본다 (L1)**
   메일에 사업자등록이 나오면 세금계산서 벌(공급가액에 부가세 별도)로 대가 조항 ②를 바꾼다.
   확인이 안 되면 원천징수 조항으로 두고 보고에 적는다.

3. **생성 스크립트를 복사한다 (L1)**
   `편집자님 계약서/etc/` 에서 가장 최근 `*_계약서_작업/build_contract_*.py` 를 새 작업 폴더로 복사한다.
   위쪽 값(`EUL_NAME`, `DATE`, `BASENAME`, `FEE_TEXT`, `TERM_TEXT`)과 바뀐 조문만 고친다.
   언어판이 없는 계정이면 언어판 정의(제2조 4호), 언어판 제작(제3조 ③④), 언어판 순서(제6조 ②, 제7조 ③⑤),
   대가의 언어판 문구(제8조 ①)를 뺀다.

4. **스크래치에서 뽑는다 (L1)**
   ```bash
   OUT_DIR=<스크래치> python build_contract_<이름>.py
   ```
   LibreOffice 로 PDF 를 뽑고 PyMuPDF 로 쪽수, 가운뎃점과 줄표, 필수 문구를 검사한다.
   `금지 문자: 없음` 과 `필수 문구 누락: 없음` 이 보이면 성공이다.

5. **눈으로 본다 (L1)**
   PDF 를 쪽마다 이미지로 연다. 서명란은 200dpi 로 확대해서 법인 도장이 대표자 칸 안에 있고
   위아래 줄 글자를 덮지 않는지 본다.

6. **드라이브에 넣는다 (L1)**
   docx 와 pdf 는 `편집자님 계약서/` 에, 스크립트와 `artifact.md` 는 `etc/<성명>_계약서_작업/` 에 둔다.
   복사한 뒤 `cmp` 로 스크래치 파일과 같은지 확인한다.

7. **보고한다**
   파일 절대경로, 공고에서 바뀐 조건, 이번에 정한 값, 편집자가 채울 빈칸(생년월일, 연락처, 주소, 서명)을 짧게 적는다.

## 조문 원칙

- 꼴은 바탕체 표준계약서(①②③ 항, 쪽번호, 갑과 을 서명표, 법인 도장)다. 예전 Pretendard 편집자 계약서(10조)는
  260907 대표 피드백 전 꼴이라 원본으로 쓰지 않는다
- 결과물 권리는 발생과 동시에 갑에게 귀속하고, 고객사에 넘길 수 있게 하고, 저작인격권 불행사를 넣는다.
  고객사 계약에서 콘텐츠를 발생 즉시 고객사에 귀속하기로 약속했기 때문이다
- 갑의 의무는 줄인다. 검수 회신 기한과 기한이 지나면 검수 완료로 보는 조항은 넣지 않는다
- 갑은 최소 물량을 보장하지 않는다. 편집자가 말한 주당 가능 편수는 "그 이내 요청은 수락한다"는 을의 약속으로만 넣는다
- 서명란 을 칸은 성명만 채우고 생년월일, 연락처, 주소는 비운다. 계좌는 서명란에도 조문에도 적지 않는다
  (조문은 "을이 지정한 계좌")
- 계약기간은 3개월, 종료 통보가 없으면 3개월씩 자동 연장한다
- 가운뎃점과 줄표를 쓰지 않는다. 법령명은 가운뎃점 없는 약칭으로 쓴다

## 산출물

- `편집자님 계약서/영상편집_업무위탁계약서_<성명>님.docx`, `.pdf`
- `편집자님 계약서/etc/<성명>_계약서_작업/build_contract_<이름>.py`, `artifact.md`

## 완료 검사

- [ ] (기계) docx 와 pdf 가 폴더에 있고 스크래치 파일과 `cmp` 가 같다
- [ ] (기계) PDF 가 4쪽 안팎이고, 가운뎃점과 줄표가 없고, 을 성명과 단가가 들어 있다
- [ ] (사람) 법인 도장이 대표자 칸 안에 있고 다른 글자를 덮지 않는다
- [ ] (사람) 공고에서 바뀐 조건이 모두 조문에 들어갔다

## 알려진 함정

- 편집몬 원문 `employ_detail.html?cmd=closing&no=<번호>` 를 L3 으로 열면 자동 판정기가 공고 마감 같은 쓰기 동작으로 보고 막는다.
  로그아웃 주소 `employ_detail.html?no=<번호>` 는 마감 공고라 "조회할 수 없습니다" 로 튕긴다 → 공고 md 를 원본으로 쓴다
- 법인 도장 1.3cm 는 서명표 기본 줄 높이보다 커서 위아래 줄 글자를 덮는다 → 대표자 줄만 `trHeight` 1.45cm(`atLeast`)로 높이고
  도장을 y -0.39cm 에 띄운다
- 예전 편집자 docx 중에는 생성 뒤 손으로 고쳐져 계좌가 두 군데 다르게 적힌 벌이 있었다 → 예전 docx 에 글자 바꾸기를 하지 말고
  스크립트로 새로 뽑는다
- LibreOffice 변환 결과를 드라이브 폴더에 바로 쓰면 동기화 중에 크기가 잘려 보일 수 있다 → 스크래치에서 뽑아 복사하고 `cmp` 로 본다

## 사람에게 물어야 하는 지점

- 계약서를 편집자에게 보내는 것(메일, 카톡). 이 업무는 파일까지만 만든다
- 단가나 기간을 합의 기록에 없는 값으로 정해야 할 때
- 사업자 편집자인데 세금계산서 조건을 모를 때
