# 사업주 부담 4대보험료 RCMS 청구

- **부르는 말**: 사업주 4대보험 RCMS 청구해줘, 사업주 부담 4대보험료 등록해줘, 4대보험 RCMS 올려줘, 사업주 4대 청구, TIPS 4대보험 처리, 밀린 4대보험 청구해줘
- **미리 허가**: RCMS 연구비 사용등록 제출 (이체는 하지 않는다)
- **런너**: claude
- **제어층**: L1 → L3
- **한 번에 걸리는 시간**: 한 달 15분, 넉 달 밀리면 60~80분

`<보안>` 은 `<OPS>/machine.json` 의 `secure_root` 다. 대표 PC에만 있다.
이 업무의 상위 폴더는 `<보안>/여형준님/10 TIPS/연구비 집행 서류` 다. 아래에서 `<집행폴더>` 라고 쓴다.
`secure_root` 가 없는 PC면 시작하지 말고 "대표 PC에서만 하는 업무" 라고 알린다.

---

## 무엇을 만드는 업무인가

회사가 낸 4대보험료 중 TIPS 참여연구원 5명의 **사업주 부담분**을 연구비에서 돌려받는다.
매달 인건비(`tips-payroll-rcms`)와 별건으로 RCMS에 한 건씩 등록한다.
끝났을 때 세 가지가 남아 있어야 한다.

- `<집행폴더>/YYMMDD 26년 M월 사업주 부담 4대보험료/` 루트에 제출본만 있는 폴더
- RCMS `연구비이체실행` 목록에 그 달 건이 `실행전` 으로 올라간 상태
- `<집행폴더>/AGENTS.md` 의 "진행 이력" 표에 그 달 줄

**이체 실행은 이 업무가 아니다.** 공동인증서와 이체비밀번호가 필요해서 사람이 한다.

## 준비물

- **크롬 프로필 1** 에 RCMS 로그인. 대표 권혁찬 계정. 사람이 미리 해둔다
- 같은 프로필에 알프레드(`app.alfred.kr`) 로그인. 회사 하나은행 계좌가 연동돼 있다
- 그 달 급여대장. `tips-payroll-rcms` 가 만든 `YYMMDD 26년 M월 참여연구원 인건비/` 폴더에 있다

## 고정값

사람별 보수월액, 보험별 금액, 계상률은 **공개 저장소에 두지 않는다.**
`<집행폴더>/AGENTS.md` 의 "사업주 부담 4대보험료 월 청구 고정값" 표를 1번 단계에서 읽는다.

| | |
| --- | --- |
| 과제번호 | `25465584` |
| 증빙선택 / 항목 / 세부항목 | `기타` / `인건비` / `참여연구원 인건비` |
| 품목명, 지급용도 | `26년 MM월 사업주 부담 4대보험료` (월은 두 자리) |
| 부가세 | `0` |

## 산식

- 국민연금, 건강보험, 장기요양 사업주분 = 같은 달 **급여대장 근로자 공제액과 같은 금액**
- 고용보험 사업주분 = 보수월액 x 1.15% (실업급여 0.9% + 고용안정 0.25%), 10원 미만 버림
- 산재보험 = 보수월액 x 0.95%, 10원 미만 버림
- 대표이사는 고용, 산재 0원
- **급여대장의 `건강보험 정산` `장기요양 정산` 칸에 숫자가 있는 달은 이 산식을 쓰지 않는다.**
  공단 개인별 고지산출내역(4대사회보험 정보연계센터, 공동인증서 필요)을 사람에게 받아
  고지보험료 기준으로 다시 계산한다. 2월처럼 마이너스가 나오면 RCMS 지급대상에는 배분값,
  현황표에는 실제값을 쓰고 배분 소명서를 같이 낸다

## 절차

1. **어디까지 했는지 본다 (L3)**
   RCMS `연구비현황` → `연구비사용내역` → `당해년도` → `조회`. 품목명에 `사업주 부담 4대보험료`
   가 있는 달을 센다. `<집행폴더>/AGENTS.md` 의 진행 이력 표와 맞춘다.
   **보험료는 다음 달 10일에 출금된다.** 오늘이 10일 전이면 지난달분은 아직 못 한다.

2. **고정값과 급여대장을 읽는다 (L1)**
   AGENTS.md 고정값 표와, 할 달마다 급여대장 PDF 의 5명 공제액을 대조한다.
   공제액이 표와 다르거나 정산 칸에 숫자가 있으면 그 달은 "산식" 의 예외 길로 간다.

3. **출금 증빙을 뜬다 (L3)**
   `https://app.alfred.kr/bank/bank-transactions?fromDate=<귀속월 다음달 1일>&toDate=<오늘>&pickerType=custom&page=1&search=26MM`
   `search=2606` 이면 `2606국민연금` `2606국민건강` `2606고용보험` `2606산재보험` 만 남는다.
   화면 캡처를 저장하고 행(일시, 적요, 출금액)을 받아 적는다.
   **이게 보이면 성공**: 네 보험이 다 있다. 한 보험이 두 번 나뉘어 나가거나 다음 달에 늦게 나간 경우도 있다(6월분 산재는 8/10).

4. **제출 파일을 만든다 (L1)**
   `<집행폴더>/etc/scripts/build_employer_insurance_*.py` 최신본을 복사해 월, 출금 행, 캡처 경로를 고쳐 돌린다.
   만드는 것:
   - 루트: `급여명세서_26년 MM월 급여대장.pdf`(복사), `계좌이체증명_26년 MM월 사업주 4대보험료 이체내역.pdf`(캡처+출금표),
     `참여연구자현황표_26년 MM월.xlsx`
   - `기타/`: 산출식 xlsx, pdf, `산출 및 이체내역 설명서.pdf`, 고지산출내역이 있으면 그 xlsx
   - `내부자료_YYMMDD/00 RCMS 등록 메모.txt`
   현황표는 가장 최근 인건비 현황표를 복사해 사업주 부담 칸을 채우고, 그 달 뒤 칸은 비운다.
   서식 기준(열 숨김 금지, 미래월 숫자 금지, 빨간 마이너스 금지)은 `tips-payroll-rcms` 와 같다.

5. **RCMS 증빙우선 등록 (L3)** 한 달에 한 건씩 한다
   `연구비사용` → `연구비사용등록` → `증빙우선 등록` 탭.
   1. `증빙선택` → `기타`. 행의 `항목` → `인건비`, `세부항목` → `참여연구원 인건비`
   2. `품목` 입력, `공급금액` 에 합계, Tab. 사용금액이 따라 바뀐다
   3. `인건비내역` 열의 `등록하기` → 참여연구자 5명 머리 체크박스 → `대상 추가` → `예`.
      아래 지급대상 5줄에 지급년월(`2026MM` 입력 후 Tab), 월별인건비계상률, 지급금액을 넣는다.
      **줄 순서는 권혁찬, 김호준, 여형준, 장원태, 홍현석이다.** 이름 순서가 아니다.
      `입력금액 합계` 가 사용금액과 같으면 `적용`. 행에 `등록완료` 가 뜬다
   4. `증빙자료첨부` 의 `등록하기` → 슬롯별 `+` 로 파일을 넣는다(아래 "파일 올리는 법").
      급여명세서, 계좌이체증명(둘 다 필수), 참여연구자현황표, 기타. `저장` → `저장이 완료되었습니다` → 창 닫기
   5. 아래 `거래처 및 계좌정보` → 대표자, 사업자주소 입력, `예금주 조회`, 지급용도 입력 → `입력확인`.
      버튼이 빨강에서 파랑으로 바뀐다
   6. 오른쪽 아래 `등록` → `예` → **`성공적으로 저장되었습니다`**

6. **확인하고 기록한다 (L3 → L1)**
   `연구비이체실행` → 과제 선택 → `조회`. 그 달 건이 `실행전` 으로 있는지 본다.
   AGENTS.md 진행 이력 표에 줄을 넣고, 이체만 남았다고 알린다.

## 파일 올리는 법

RCMS 파일추가 창은 OS 파일 선택창을 띄우므로 버튼을 누르지 않는다. `tips-claude-rcms` 의 우회와 같다.
슬롯 `+` → find 로 file input → L3 파일 업로드에 절대경로 → 페이지 스크립트로 Kendo input 에 옮긴다.

```js
window.__mv = function(){const $=window.jQuery; const ins=[...document.querySelectorAll('input[type=file]')];
const src=ins.find(i=>i.files&&i.files.length&&!$(i).data('kendoUpload')); const t=ins.find(i=>$(i).data('kendoUpload'));
if(!src||!t) return {src:!!src,t:!!t,n:ins.length}; const dt=new DataTransfer(); [...src.files].forEach(f=>dt.items.add(f));
t.files=dt.files; t.dispatchEvent(new Event('change',{bubbles:true})); return {moved:[...src.files].map(f=>f.name)};}; __mv()
```

`기타` 슬롯처럼 find 가 바로 Kendo input 을 잡으면 업로드만으로 들어가고 `__mv()` 는 `src:false` 를 돌려준다. 정상이다.
넣은 뒤에는 화면 대신 `td, span` 텍스트에서 파일 이름을 뽑아 확인한다.

## 알려진 함정

- **크롬을 잘못 고르면 RCMS 가 로그인 화면이다** → 확장 연결이 셋(`Browser 1~3`)이고 시크릿 창도 하나로 잡힌다.
  261006 에 시크릿 창에 탭을 열어 사람이 보던 창을 가렸다. 시크릿 창이 열려 있으면 새 탭 그룹이 거기 생긴다.
  판정: 새 탭에서 `rcms.go.kr/main.do` 제목이 `RCMS 로그인` 이면 틀린 창이다. 탭을 닫고 다른 deviceId 를 고른다.
  사람이 시크릿 창을 닫은 뒤 같은 deviceId 로 `tabs_context_mcp{createIfEmpty}` 하니 프로필 1 에 열렸다
- **드롭다운은 두 번 눌러야 열릴 때가 있다** → 등록 직후 폼이 리셋되면 첫 클릭이 포커스만 가져간다. 열렸는지 화면으로 보고 고른다
- **`대상 추가` 가 "선택된 참여연구자가 없습니다" 를 띄운다** → 팝업이 늦게 떠서 체크가 안 먹은 것. `확인` 후 머리 체크박스를 다시 누른다
- **이체 실행 화면에 `이체비밀번호 설정` 창이 뜬다** → `다음에 변경하기` 를 누른다. 보안 설정이라 바꾸지 않는다
- **이체 실행 시간은 09:00~20:00** 이다. 사람에게 넘길 때 같이 알린다
- **현황표의 2~4월 값이 뒤바뀐 파일이 있었다** → 260910 8월 인건비 현황표는 김호준과 홍현석의 2~4월 사업주 부담값이 서로 바뀌어 있었다. 4월 제출본과 AGENTS.md 기준으로 바로잡는다
- **공단 고지산출내역은 에이전트가 못 받는다** → 공동인증서 로그인이다. 정산 없는 달은 급여대장 공제액 산식으로 가고, 받아오면 나중에 기타 칸에 추가한다
- **은행 거래내역확인증도 에이전트가 못 받는다** → 하나은행 기업뱅킹이 공동인증서다. 알프레드 화면 캡처로 등록하고, 사람이 확인증을 받으면 `연구비사용내역` → `증빙파일수정` 으로 바꾼다
- **인건비 예산이 연말에 빠듯하다** → 261006 기준 남은 인건비 예산으로 9~12월 인건비와 4대보험을 다 덮기에 약 57만 원 모자란다. 등록 전에 `사용한도` 의 인건비 본예산 잔액을 본다

## 사람에게 물어야 하는 지점

- RCMS, 알프레드 로그인이 풀렸을 때
- **연구비 이체 실행.** 공동인증서와 이체비밀번호라 무조건 사람이 한다
- 급여대장에 건강, 장기요양 정산 숫자가 있거나 공제액이 고정값과 다른 달
- 인건비 예산 잔액이 그 달 금액보다 적을 때
