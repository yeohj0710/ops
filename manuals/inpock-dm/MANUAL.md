# 인포크링크 DM 자동화 세팅

- **부르는 말**: 인포크 세팅해줘, DM 자동화 세팅, 댓글 자동화, 자료형 릴스 세팅
- **런너**: claude
- **제어층**: L3 (로그인된 크롬)
- **한 번에 걸리는 시간**: 15~25분

---

## 무엇을 만드는 업무인가

자료형 릴스에 "댓글에 ○○ 남겨주시면 정리한 자료 보내드려요" 를 걸어두고,
댓글이 달리면 **공개 답글 + DM** 이 자동으로 나가게 세팅한다.
팔로우한 사람에게만 자료를 주는 구조라 팔로워가 늘어난다.

## 쉬운 설명

**어떤 때 씁니까.** 약사님 인스타그램에 자료형 릴스를 올렸습니다. "댓글에 '자료' 라고 남겨주시면 정리본 보내드려요" 를 걸어서 팔로워를 늘리고 싶을 때 씁니다.

**뭐라고 말하면 됩니까.** "인포크 세팅해줘" 라고 하면서 어느 계정에, 어떤 단어를 댓글로 받을지, 어떤 자료 링크를 보낼지 알려주면 됩니다.

**그러면 무슨 일이 벌어집니까.**

1. 이미 로그인해 둔 크롬으로 인포크링크 관리자 화면에 들어갑니다.
2. 성적이 잘 나온 기존 세팅을 복제해서 시작합니다. 처음부터 만들면 빠뜨리는 칸이 생깁니다.
3. 네 단계를 채웁니다. 댓글에 공개 답글을 달지, 팔로워와 안 팔로우한 사람에게 다른 메시지를 보낼지, 어떤 단어가 달린 댓글에 반응할지, 어느 게시물에 걸지입니다.
4. DM 문구를 세 벌 씁니다. 모두에게 가는 것, 팔로워에게 가는 것, 아직 팔로우하지 않은 사람에게 가는 것입니다. 약사님마다 말투가 달라서 그 계정 글투에 맞춥니다.
5. 세팅한 내용을 채팅에 요약해서 찍어 줍니다. 켜기 전에 사람이 눈으로 확인합니다.

**끝나면 무엇이 남습니까.** 댓글이 달리면 공개 답글이 자동으로 달리고, 팔로우한 사람에게는 자료 링크가 DM 으로 갑니다. 아직 팔로우하지 않은 사람에게는 팔로우해달라는 안내가 먼저 갑니다.

**되돌릴 수 없는 것이 하나 있습니다.** 2단계에서 "팔로우 여부에 따라 다르게 보내기" 를 한 번 켜면 다시 끄지 못합니다. 누르기 전에 확인합니다.

## 실제 화면 구성 (실측)

편집 화면은 **4단계 + 다음**, 다음을 누르면 **DM 문구 화면**이 나온다.

### 1단계. 답글을 남겨볼까요?

댓글에 달리는 **공개 답글**이다. 선택지는 아니요 / 랜덤하게 / 정중하게 / 친근하게 / **직접** 다섯이다.
본보기는 `직접` 에 답글 7개를 넣고 랜덤으로 돌린다.

```
DM 공유드렸습니다🤍 확인 부탁드려요! (요청함도 확인해주세요🎁)
감사합니다💚 DM 확인 부탁드려요🔥
감사합니다☺️ DM 공유드렸으니 확인 부탁드려요! (요청함도 확인해주세요👍)
DM 전달 드렸습니다🔥 메세지 요청함도 확인 부탁드려요🙌
감사합니다☺️ DM 확인 부탁드려요!📬 (메세지 요청함도 확인 부탁드려요!)
감사합니다😍 DM 전달드렸으니 확인 부탁드려요🙌❤️
DM 전달드렸습니다 💌
```

`요청함도 확인해주세요` 를 넣는 이유는 이렇다. 안 팔로우한 사람에게 간 DM 은 요청함으로 들어가서
본인이 안 보면 모른다.

### 2단계. 팔로우 여부에 따라 다르게 보낼까요?

> **한번 설정하면 이후 수정이 불가능하다.** 화면에 그렇게 적혀 있다.

`팔로워/비팔로워 다르게 메시지를 전송할래요` 를 고른다. 본보기가 그렇게 되어 있다.
**잘못 고르면 그 건은 못 고치고 새로 만들어야 한다.** 누르기 전에 두 번 확인한다.

### 3단계. 어떤 댓글에 메시지를 보낼까요?

키워드다. 본보기는 `생리대`. 사람이 준 낱말을 그대로 넣는다.

### 4단계. 어떤 게시물을 자동화할까요?

`직접 선택` 으로 그 릴스를 고른다.

### 다음 화면. DM 문구 (탭 셋)

**모든 고객**: 팔로우 확인용. 제일 먼저 나가는 DM.
```
댓글 남겨주셔서 감사합니다🫶
비밀 자료는 팔로워분들에게 보내드리고 있어요!
저를 팔로우해주셨다면 아래 버튼을 눌러주세요!
```
버튼: `팔로우했어요 🙌🏻`

**팔로워**: 버튼 누른 사람이 팔로워면 이게 간다. 메시지 종류는 `텍스트` / `이미지 캐러셀`.
```
감사해요! 생리대 비밀 정리 자료 전달드릴게요! 👇
```
버튼: `생리대 정리 자료 📩` ← **여기에 자료 링크를 넣는다**

**비팔로워**: 팔로우가 확인 안 되면 이게 간다.
```
앗, 팔로우 확인이 안 됐어요 😢
팔로우하셨다면, 위에서 받은 메시지의 버튼을 다시 눌러주세요!
```
버튼: `팔로우 완료했어요 🙌🏻`

## 절차

1. **키워드와 자료 링크가 있는지 본다.** 없으면 시작할 때 한 번 묻는다
2. `admin/manager/?tab=trigger` 로 간다. **왼쪽 위 계정을 확인한다.** 다르면 로그아웃→계정전환
3. 같은 계정이면 본보기 편을 **점 3개 → 복제**. 다른 계정이면 `+ 자동화 추가하기`
4. 1단계 답글 7개를 넣는다(위 문구를 그 채널 말투로 다듬는다)
5. 2단계 `팔로워/비팔로워 다르게`. **되돌릴 수 없으니 확인하고 누른다**
6. 3단계 키워드, 4단계 릴스 선택
7. DM 문구 세 탭을 채운다. 팔로워 탭 버튼에 **자료 링크**를 넣는다
8. 저장하고 **목록에서 다시 열어 값이 남아 있는지 확인한다**
9. 세팅 내용을 채팅에 코드블록으로 찍는다

## 알려진 함정

- **2단계 팔로우 분기는 한번 정하면 못 고친다.** 잘못 고르면 새로 만들어야 한다
- **로그아웃 버튼은 왼쪽 아래**다. 톱니바퀴가 아니다. 그리고 로그아웃이 곧 계정 전환 화면이다
- **계정을 먼저 확인한다.** 다 만들고 계정이 틀린 걸 알면 처음부터다
- 이 사이트는 SPA 라 `<a href>` 가 6개뿐이다. 링크를 찾지 말고 **주소로 바로 가거나 화면을 눌러라**
- 답글을 하나만 넣으면 같은 답글이 반복돼 스팸처럼 보인다. **여러 개 넣어 랜덤으로**
- 남의 돌아가는 편을 열어 보는 건 괜찮지만 **저장은 하지 마라.** 확인만 하고 나온다
- 키워드나 링크를 추측해서 넣지 마라

## 묻는 건 이것 하나뿐

**키워드와 자료 링크.** 지어낼 수 없다. 안 줬으면 시작할 때 한 번 묻는다.

나머지는 묻지 않는다.
- 계정이 안 정해졌으면 **그 릴스가 올라간 계정**에 건다
- 문구는 본보기와 채널 프로필을 보고 정한다
- 세팅은 고칠 수 있다(팔로우 분기만 빼고). 완벽을 기다리지 말고 만들어 놓고 보고한다
