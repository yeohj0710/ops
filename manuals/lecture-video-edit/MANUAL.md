# 강의 영상 편집

- **부르는 말**: 강의 영상 편집, 강의 효과 수정, 강의 무음 정리, 솔파 크리투스 참고해서 편집
- **미리 허가**: 지정 영상의 편집과 검수, 원본 백업, 기존 파일명으로 교체. 사용자가 공유를 승인한 기존 폴더의 파일 갱신. 새로운 공개 게시와 타인에게 메시지 보내기는 별도 승인 필요.
- **런너**: either
- **제어층**: L1
- **한 번에 걸리는 시간**: 영상 길이와 수정 범위에 따라 다름. 렌더 시간은 별도.

## 필수 디자인 기준

강의에 효과를 넣거나 고칠 때마다 솔파와 크리투스 강의의 실제 장면을 먼저 본다. 기억이나 제목만으로 스타일을 추측하지 않는다. 사용자가 두 강의의 형식을 따르라고 지정했다.

참고 위치는 기계 설정의 <DRIVE> 아래다.

- ㆍ기타 문서/[강의] 솔파_돈과 조회수 쓸어담는 콘텐츠의 본질
- ㆍ기타 문서/[강의] 크리투스_크리에이터 성장 올인원 패키지

적용할 효과와 목적이 같은 장면을 고른다. 파일명과 타임코드를 기록하고 전후 프레임에서 강조 위치, 크기, 글꼴 굵기, 색상, 여백, 등장과 퇴장을 확인한다. 해당 장면의 형식을 따라 작업 대상 강의의 문구와 화면으로 다시 만든다. 참고 강의의 영상, 음성, 강사 얼굴, 로고를 결과물에 넣지 않는다.

위 시간은 참고 장면을 찾는 출발점이다. 새로운 효과는 적용 전에 적합한 장면을 다시 확인한다. 지정 레퍼런스가 일반 디자인 기본값보다 우선한다.

## 편집 절차

1. **현재 파일 확인**
   사용자 타임코드가 어느 편집본 기준인지 확인한다. 현재 파일의 크기, 수정 시각, 길이, 프레임 수, 오디오 트랙, 자막을 기록한다. 이미 실행 중인 작업과 배치 예정본을 확인해 중복 렌더와 덮어쓰기를 막는다.

2. **보관과 작업 위치**
   사용자 지정 폴더에서 작업한다. 원본, 초안, 프레임, 로그, 중간 렌더는 해당 폴더의 etc 아래에 둔다. 이전 효과를 교체할 때는 효과가 들어가기 전 백업과 편집 구간표를 찾는다. 이미 들어간 효과 위에 다시 효과를 겹치지 않는다.

3. **컷 결정**
   실제 영상 프레임과 음성의 발화 경계를 함께 확인한다. 음량이 낮다는 이유만으로 말을 자르지 않는다. 음성 인식 결과에 침묵이 단어 길이로 포함될 수 있으므로 실제 음량과 대조한다. 말 더듬기, 잘못 설명한 첫 시도, 목적 없는 대기는 정리하되 따라 하기 위한 정상 반복 조작은 유지한다. 문장 중간 컷은 앞뒤 음절과 연결을 따로 검사한다.

4. **효과 배치**
   레퍼런스 장면과 수정 전후 화면을 비교한다. 설명은 빈 공간에 두고 버튼과 입력 내용을 가리지 않는다. 버튼 강조는 실제 버튼이나 글자 범위에 맞춘다. 빈 행 전체를 큰 박스로 감싸지 않는다. 화면을 확대하면 강조 요소도 같은 좌표 변환을 적용한다. 옆 안내문이 잘리는 전체 확대 대신 필요한 영역만 따로 크게 보여준다. 클릭, 화면 전환, 스크롤에 맞춰 효과가 이동하거나 끝나도록 한다.

5. **가림 경계**
   주소, 검색 기록, 개인 채팅, 전화, 다른 파일은 필요한 영역만 가린다. 흰색 가림은 실제 화면 왼쪽과 오른쪽 끝에 맞춘다. 확대 전후에도 흰색이 검은 여백으로 튀어나오거나 가느다란 원본 띠가 남지 않게 한다. 전환 직전과 직후의 한 프레임 노출도 확인한다. 기존 개인정보 처리를 보존한다.

6. **자막과 소리**
   사용자가 정정한 문구를 우선 반영한다. 자막은 문장과 의미 단위로 나누고 발화 시작과 끝에 맞춘다. 컷 이후에는 자막, 효과, 챕터 시간을 모두 다시 계산한다. 기존 오디오 트랙과 기본 재생 트랙을 보존한다. 음량 보정이 병행 중이면 새 컷 기준 파일을 전달하고 이전 시간표를 적용하지 않도록 기록한다.

7. **미리보기와 최종 출력**
   문제가 있던 시간, 효과 등장과 퇴장, 새 컷 연결을 먼저 짧게 렌더해 실제 프레임을 확인한다. 통과한 설정으로 최종본을 만든다. 기존 규격과 파일명을 유지하고 자막 있음과 없음이 필요한 작업에서는 둘 다 동일한 컷과 소리로 만든다. 최종 디코딩, 길이, 프레임 수, 오디오 수, 자막 겹침을 검사한다.

8. **기존 링크 갱신**
   배치 직전 현재 파일이 작업 시작 후 다른 작업으로 바뀌지 않았는지 확인한다. 백업 후 기존 파일을 교체한다. 승인된 공유 사본도 같은 이름으로 갱신해 파일 ID를 보존한다. 길이 안내를 수정한다. Drive 동기화와 기존 공개 권한을 확인한 뒤 링크를 전달한다.

## 완료 검사

- 수정 요청마다 근거 프레임과 변경 내용이 있다.
- 효과가 버튼, 설명, 자막, 개인정보 가림과 충돌하지 않는다.
- 컷 연결에서 발화 일부가 사라지지 않는다.
- 영상 전 구간이 오류 없이 디코딩되고 오디오 트랙이 보존된다.
- 기존 최종 파일명과 공개 링크가 유지된다.

## 알려진 함정

- 전체 확대가 옆 안내문을 자른다. 안내문은 고정하고 조작 영역만 확대한다.
- 자막이 침묵 동안 계속 떠 있으면 발화가 있다고 착각하기 쉽다. 자막 길이만으로 컷을 판단하지 않는다.
- 예전 렌더 구간표의 source가 현재 최종 파일명일 수 있다. 해당 구간표가 만들어질 당시의 백업을 입력으로 사용한다.
- 여러 작업이 같은 강의를 고치면 이전 타임코드나 음량으로 덮어쓸 수 있다. 변경 파일을 다시 분석하고 작업 기록을 공유한다.
- 매뉴얼 동기화가 다른 작업의 변경까지 덮어쓰지 않도록 범위를 확인한다. 원본 매뉴얼과 드라이브 사본의 내용이 같은지 검사한다.

## 런칭 통합 검수와 두 버전 납품

프로젝트의 에이전트 기억에서 이전 사용자 피드백, 최종 파일 목록, 교재·실습·상세페이지 링크를 찾는다. 새 세션은 과거 초안과 최신 정본을 구분한다. 영상 한 편에서 발견한 반복 결함은 다른 편에도 같은 기준으로 검사한다. 번호가 비었다는 이유만으로 미편집으로 판단하지 않는다.

자막 없음은 최종 편집표에서 말자막만 제외해 출력한다. 설명 슬라이드, 화면 글자, 버튼 강조, 개인정보 가림, 컷과 소리는 자막 있음과 같다. 화면을 자르거나 자막 영역을 흐리게 처리해서 만들지 않는다. 두 버전의 길이를 한 프레임 이내로 비교하고 모든 음성 트랙의 패킷 해시를 대조한다. 납품 사본과 정본의 SHA-256도 비교한다.

새로 복원한 음성·영상 구간은 기존 가림의 적용 범위를 다시 확인한다. 컷을 바꾸면 자막, 효과, 챕터와 실습·교재 타임코드를 함께 계산한다. 최종 MP4, SRT, 교재 목차, 실습 폴더와 ZIP, 파일 안내, 상세페이지의 이름과 제공 수를 맞춘다.

상세페이지는 실제 최종 편집 프로젝트 URL과 노드 ID, 전체 이미지, 구간별 이미지와 미리보기를 승인된 공유 폴더에 둔다. Figma의 텍스트 값이 바뀌어도 내보내기에 예전 문구가 남은 사례가 있다. 최종 전체 이미지에서 수정 문구와 줄바꿈을 다시 읽고 저장한다. 원본과 과거 시안은 보존하되 납품 정본으로 오인되지 않게 안내한다.

교재는 현재 조판 소스를 보존하고 실제 출판된 교재의 본문 페이지를 참고한다. 이미지 원본과 출력 크기의 해상도, 정적 글꼴, 넘침과 모든 페이지 렌더를 확인한다. 참고 강의 PDF를 출판된 교재라고 기록하지 않는다. 실습자료는 실제 사용 파일의 허용 목록을 만들고 폴더와 ZIP의 경로·개수·내용 해시를 비교한다.

Drive 텍스트 검색이 MP4를 누락한 사례가 있다. 검색 결과가 없다는 이유로 파일 미존재를 단정하지 않는다. 해당 폴더를 직접 열거하거나 정확한 파일 ID로 메타데이터를 확인한다. 클라우드 파일의 크기·내용과 기존 공개 권한을 확인한다.

백그라운드 실행과 다운로드는 성공 종료만으로 판단하지 않는다. 대괄호 경로를 문자 그대로 처리하고 파일 크기·디코딩·실제 치수를 검사한다. 다운로드가 오류 없이 0바이트를 저장한 사례가 있다. 폰트 변경은 필요한 폰트를 먼저 모두 불러온 뒤 수행한다. 누락 글꼴을 이유로 전체 디자인을 일괄 교체하지 않는다.

반복 업무의 공통 절차는 이 매뉴얼에, 프로젝트의 정확한 경로·영상별 지적·Figma ID·현재 상태는 비공개 에이전트 기억에 기록한다. 새 세션이 실제 검증과 미완료 항목을 구분할 수 있게 한다.
검수 캐시는 현재 편집표와 출력 해시에 연결한다. 전사나 음량 결과가 새 파일보다 오래됐으면 재사용 근거를 확인한다. 자막·가림만 바뀌고 음성 패킷이 그대로인 경우에는 같은 발화 경계 검사를 재사용할 수 있다. 컷이나 음성이 바뀌면 현재 출력에서 다시 검사한다.

휴대폰 실습 화면 양옆에 고정 설명이 있으면 휴대폰 영역만 확대한다. 전체 화면 확대가 설명란을 자르는지 실제 전환과 최종 출력에서 확인한다. 개인정보 가림은 대화상자가 닫히거나 불투명한 재생기가 나타나는 정확한 프레임에서 끝낸다. 가림이 끝난 뒤 다른 개인정보가 드러나는지도 확인한다.

보충 슬라이드도 본 강의의 공통 양식과 로고를 따른다. 기존 영상의 어두운 프로그램 화면과 새로 만든 설명 슬라이드를 구분한다. 슬라이드·가림을 다시 조합하면 이전 음량 보정이 사라질 수 있으므로 마지막 조합 뒤 실제 기본 음성·마이크를 측정한다. 이전 타임라인의 보정 음원을 새 컷에 붙이지 않는다.

실습 폴더와 ZIP의 정식 이름은 현재 파일 목록과 Drive ID로 확인한다. 공백이 있는 이름을 추측으로 바꾸지 않는다. 영상 수정 뒤 실습 안내의 시간은 편집표로 옮기고 해당 장면을 실제 확인한다. Windows의 한글 경로에서 OpenCV 이미지 저장이 실패하면 인코딩한 바이트나 PIL로 저장하고 파일 존재·크기·내용을 검사한다.
