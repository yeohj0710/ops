# 김제조 시스템 동기화

- **부르는 말**: 김제조 시스템 동기화해줘, 김제조 동기화, 김제조 보드 맞춰줘, 김주성 대표님 콘텐츠 동기화, 김제조 영상 마이박스에 올려줘
- **런너**: claude
- **제어층**: L1 (영상 폴더 훑기), L3 (노션과 김제조 보드)
- **한 번에 걸리는 시간**: 20~40분

---

## 무엇을 만드는 업무인가

김주성 대표님(활동명 **김제조**)은 본인 콘텐츠를 <https://www.kimjejopharm.xyz/> 에서 관리한다.
우리 진행 상황은 노션에 있다. 그 둘을 맞추는 일이다.

일이 둘로 나뉜다.

1. **노션 표 두 개를 보고 김제조 보드에 반영한다.** 우리 담당분만 손댄다.
2. **편집한 영상을 네이버 마이박스에 올린다.** 대표님 요청이다.

## 쉬운 설명

### 쓰는 상황

김주성 대표님 영상이 촬영되고 편집되는데, 진행 상황은 우리 노션에만 쌓입니다.
대표님은 본인 사이트에서 보시기 때문에 그쪽이 며칠씩 뒤처집니다. 그걸 맞출 때 씁니다.

### 시키는 말

Claude 나 Codex 새 세션에 이렇게 말하면 됩니다.

> G드라이브 에이전트 폴더 참고해서 김제조 시스템 동기화 업무 해줘

영상 업로드만 원하면 "김제조 영상 마이박스에 올려줘" 라고 하면 됩니다.

### 진행 순서

1. 노션 두 곳에서 **김주성 대표님 것만** 뽑습니다. 콘텐츠 기획안 목록과 편집 진행도입니다.
   다른 약사님 콘텐츠가 같은 표에 섞여 있어서 인플루언서 칸을 꼭 봅니다.
2. 김제조 보드를 엽니다. 크롬에 이미 로그인돼 있습니다.
3. **담당자가 권혁찬인 카드가 우리 것입니다.** 그 카드들만 만집니다.
   김주성, 강민형, 유현일, 정보민 담당 카드는 대표님 쪽 사람들 것이라 건드리지 않습니다.
4. 노션과 보드를 맞춰 봅니다. 진행 단계가 달라졌으면 카드를 끌어 옮기고,
   보드에 아예 없는 콘텐츠는 새로 만듭니다.
5. **제목이 서로 다릅니다.** 대표님이 본인 채널 말투로 바꿔 두셔서
   "서울대 약사는 안 사는 영양제" 가 보드에서는 "서울대 약공장 대표는 안 사는 영양제" 입니다.
   글자로 찾지 말고 뜻으로 맞춰야 합니다.
6. 편집이 끝난 영상을 네이버 마이박스에 올립니다. 가편집본과 최종본 두 가지입니다.
7. 무엇을 옮겼고 무엇이 안 맞았는지 채팅에 표로 찍고 보고 파일에 남깁니다.

### 결과물

김제조 보드의 권혁찬 담당 카드가 노션과 같은 단계에 있게 됩니다.
마이박스에는 오늘 편집분이 올라가 있습니다.

### 주의할 점

**남의 시스템입니다.** 우리 담당(권혁찬) 밖의 카드는 읽기만 합니다.
지우거나 다른 사람 카드를 옮기지 않습니다.

## 절차

1. **노션에서 김주성 대표님 건을 뽑는다 (L3)**
   위 두 데이터소스를 질의한다. 편집 진행도는 `인플루언서 = '김주성 대표님'` 으로 거른다.
   제목, 진행 상태, 편집자, 업로드 예정일, 비고를 가져온다.

2. **김제조 보드를 연다 (L3)**
   <https://www.kimjejopharm.xyz/> 로 간다.

   **크롬이 여러 개면 두 번째 것에 붙는다.** 260818 실측으로 보드 세션은 **Browser 2** 에만 살아 있다
   (유현일, 외부 파트너로 로그인돼 있다). Browser 1 에서는 로그인 창이 뜨고 크롬에 저장된 비밀번호도
   없어서 아이디 칸을 눌러도 아무것도 안 떠오른다. 로그인 창을 만나면 붙은 크롬부터 바꿔 본다.

3. **보드에서 권혁찬 카드를 전부 읽는다 (L3)**
   클릭하지 말고 DOM 으로 읽는다. 이게 제일 안전하고 빠르다.

   ```js
   [...document.querySelectorAll('div.card')].map(c => ({
     제목: c.firstElementChild?.textContent.trim(),
     배지: c.querySelector('.badges')?.textContent.trim(),
     담당: c.querySelector('.meta')?.textContent.trim(),
     단계: c.closest('[class*=col],section')?.querySelector('h2,h3')?.textContent.trim(),
   })).filter(x => (x.담당||'').includes('권혁찬'))
   ```

4. **짝을 맞춘다 (L1)**
   노션 제목과 보드 제목이 다르다. **뜻으로 맞춘다.** 260818 실측한 대응은 이렇다.

   | 노션 | 김제조 보드 |
   | --- | --- |
   | 서울대 약사는 안사는 영양제 | 서울대 약공장 대표는 안 사는 영양제 |
   | 서울대 약사의 종합비타민 티어표 | 약공장 돌리는 약사의 종합비타민 티어표 |
   | 서울대 약사가 말해주는 딥슬립 영양제 TOP5 | 약공장 약사가 말해주는 딥슬립 영양제 TOP5 |
   | 약사가 보는 최악의 습관은? | 약사가 보는 최악의 습관은? (토너먼트) |
   | 3 제품 3개의 효능 | 3 제품 3개의 효능 (여드름 약국템) |
   | 두통약 뭐먹어야해요? | 두통약 뭐 먹어야 해요? |
   | 이 약국은 귀신이 많아요 (밈) | 이 약국은 귀신이 많아요 (밈) |

   **"서울대 약사" 가 보드에서는 "약공장 대표" 나 "약공장 약사" 로 바뀐다.**
   새 카드를 만들 때도 이 말투에 맞춘다.

5. **단계를 옮기고 없는 것을 만든다 (L3)**
   카드는 `draggable` 이라 단계 사이를 끌어 옮긴다.
   보드에 없는 콘텐츠는 `+ 콘텐츠 추가`(`#btn-new`)로 만들고 담당자를 권혁찬으로 둔다.

   **한 건 옮길 때마다 화면에서 결과를 확인한다.** 여러 개를 몰아서 하고 나중에 세면 틀린다.

   ### 카드 하나 만드는 순서 (260818 실측, 이대로 하면 걸리지 않는다)

   이 화면에서는 **`form_input` 과 `find` 가 45초 타임아웃으로 죽는다.** 값은 스크립트로 넣고
   버튼은 진짜로 눌러야 한다. 네 걸음을 한 세트로 돈다.

   1. `+ 콘텐츠 추가` 를 **진짜 클릭**한다
   2. 값을 **스크립트로** 넣는다. `input` 과 `change` 를 같이 쏜다

      ```js
      const all=[...document.querySelectorAll('input,select,textarea')];
      // all[9] 제목, all[10] 단계, all[11] 차별점
      const set=(el,v)=>{el.value=v; el.dispatchEvent(new Event('input',{bubbles:true}));
                         el.dispatchEvent(new Event('change',{bubbles:true}));};
      set(all[9],'제목'); set(all[10],'편집'); set(all[11],'제품 빌드업');
      const cb=v=>{const b=all.find(e=>e.type==='checkbox'&&e.value===v);
                   if(b&&!b.checked){b.checked=true;b.dispatchEvent(new Event('change',{bubbles:true}));}};
      cb('인스타 릴스'); cb('4c06786f-6a61-4fd8-999b-4faa9dcd24a5');  // 권혁찬
      ```

      담당자 체크박스는 **이름이 아니라 UUID** 다. 권혁찬은 `4c06786f-6a61-4fd8-999b-4faa9dcd24a5`.
      바뀌었으면 `[...document.querySelectorAll('input[type=checkbox]')].map(b=>[b.value,(b.closest('label')||b.parentElement).textContent.trim()])` 로 다시 뽑는다.
   3. 서랍 위에서 **진짜로 스크롤**을 굴려 바닥까지 내린다. 저장 버튼이 보여야 한다
   4. `저장` 을 **진짜 클릭**한다. 서랍이 닫히면 성공이다

   **저장됐는지는 카드 수로 센다.** `document.querySelectorAll('div.card').length` 가 하나 늘어야 한다.

6. **마이박스에 영상을 올린다 (아래 절 참고)**

7. **보고한다 (L1)**
   옮긴 카드, 새로 만든 카드, 못 맞춘 것을 표로 채팅에 찍는다.
   드라이브 `에이전트/보고/<날짜>-김제조동기화.md` 에도 남긴다.

## 영상 고르기

`<드라이브>/영상 편집/.김주성 대표님/<주제 폴더>/` 안은 이렇게 생겼다.

| 파일 | 무엇 | 마이박스에 |
| --- | --- | --- |
| `IMG_1913.MOV` 같은 것 | 카메라 원본 (수백 MB) | 올리지 않는다 |
| `보정본.mp4` | 가편집본 | **올린다** |
| `bgm 삽입.mp4` | 중간 산출물 | 올리지 않는다 |
| `<편집자 이름>/제목_1.2x_수정2.mp4` | 편집 최종본 | **올린다** |

- **편집자 폴더 안이 최종본이다.** 폴더 이름이 편집자 이름이다(엄성미, 권성은).
- **차수가 높은 것이 최신이다.** `_수정1` `_수정2` 가 있으면 **숫자가 제일 큰 것**을 쓴다.
  `_1.2x` 는 배속본이고 이게 실제로 올라가는 버전이다.
- **폴더 이름의 날짜(`260804`)를 믿지 마라.** 촬영일이지 편집일이 아니다.
  판단은 **파일 수정 시각**으로 한다.

무엇을 올릴지는 이렇게 고른다.

```bash
# 최근 편집분을 수정 시각 순으로 본다
node -e "..."   # 아래 '고르는 기준' 참고
```

### 고르는 기준

- **오늘 수정된 파일**이 1순위다. 편집자가 오늘 손댄 것이다
- **어제나 그저께 것도 올린다.** 마이박스 쪽이 며칠 밀려 있을 수 있다
- **오래됐는데 아직 안 올라간 것은 올리지 마라.** 안 올린 이유가 있다.
  폐기됐거나 대표님이 반려한 건이다. 노션에서 그 건의 상태를 먼저 확인한다
- 헷갈리면 **노션 상태가 `폐기` `반려됨` `(보류)` 인 것은 빼고** 나머지를 올린다

## 마이박스 업로드 (260818 기준 막혀 있다)

**대표님 요청은 이렇다.** 만든 영상을 네이버 마이박스에 파일로 저장해 둔다.
가편집본과 편집 최종본 두 가지면 된다.

올릴 자리는 마이박스 지정 폴더다. 계정과 폴더 주소는 드라이브 `자격증명/계정.md` 에 있다.

**지금 에이전트가 못 한다. 260818 에 실제로 막혔다.**

| 시도 | 결과 |
| --- | --- |
| 크롬 익스텐션(L3)으로 mybox.naver.com 열기 | **차단.** "이 사이트는 안전 제한으로 허용되지 않는다" |
| 마이박스 데스크톱 앱으로 L1 복사 | **없다.** 이 기계에 설치돼 있지 않다 |

그래서 지금은 **사람이 올린다.** 에이전트는 여기까지 해 둔다.

1. 올릴 파일 목록을 만든다. 주제, 가편집본 경로, 최종본 경로, 수정 시각을 표로 찍는다
2. 그 파일들을 한 폴더(`<드라이브>/영상 편집/.김주성 대표님/_마이박스 올릴 것/<날짜>/`)에
   **복사해 모아 둔다.** 사람이 끌어다 놓기만 하면 되게
3. **이름을 마이박스 규칙으로 바꾼다.** 아래 "올릴 때 파일 이름" 을 따른다
4. **이미 올라간 것을 빼 달라고 사람에게 말한다.** 아래 "이미 올라간 것" 을 따른다
5. 채팅과 보고 파일에 "이 폴더를 마이박스 `약공장 김제조 / 3. 인스타그램` 에 올려 주세요" 로 남긴다

### 올릴 때 파일 이름

마이박스는 **`YYMMDD 제목.mp4`** 하나로 통일돼 있다. `260813 (10년차 약공장 약사의) 다이소 영양제 티어리스트.mp4`
같은 식이다. `[최종본]` `[가편집본]` 같은 대괄호 접두사나 `_1.2x` 같은 꼬리표는 **거기 없다.**
드라이브 안에서 쓰는 이름을 그대로 올리면 형식이 깨진다.

- **날짜는 게시일이다.** 김제조 보드 게시 일정 탭에 적힌 날을 쓴다. 노션 업로드 예정일과 하루씩
  다른 경우가 있는데 **보드 쪽을 쓴다.** 다르면 보고에 적는다
- 게시일이 안 잡힌 건(전화로 들어온 건 같은 것)은 촬영 폴더 날짜를 쓴다
- 가편집본과 최종본이 둘 다 올라가면 이름이 겹친다. 가편집본만 **`(가편집본)`** 을 뒤에 붙인다.
  마이박스에 이미 `260730 이 사람은 약사입니다 (최종본).mp4` 가 있어 괄호 표기는 규칙 안이다
- `_1.2x` 는 떼고 올린다. 배속본이 원래 올라가는 버전이라 굳이 표시하지 않는다

### 이미 올라간 것

**마이박스가 크롬에서 차단돼 에이전트는 목록을 못 본다.** 그래서 이미 올라간 것을 스스로 못 거른다.
260818 에 실제로 두 개를 중복으로 모아 놨고, 사람이 화면을 보여줘서 걸렀다.

- 모을 때 **드라이브 `업로드 완료` 폴더에 있는 건 이미 올라갔을 가능성이 높다.** 그것부터 의심한다
- 그래도 확실하지 않으니 **보고에 "마이박스에 이미 있으면 빼 주세요" 를 파일 목록과 함께 적는다**
- 크기가 같은 파일이 마이박스에 있으면 같은 것이다. 목록에 크기가 보이니 사람이 바로 대조한다

**뚫리면 이 절을 고쳐라.** 마이박스 데스크톱 앱을 깔면 L1 파일 복사로 끝난다.
그게 제일 확실한 길이라 사람에게 한 번 권해 볼 만하다.

## 알려진 함정

- **차별점이 미정이면 저장이 조용히 안 된다.** 260818 에 이걸로 한참 헤맸다.
  오류도 안 뜨고 알림도 없다. 서랍만 그대로 열려 있어서 클릭이 안 먹은 줄 알게 된다.
  칸 이름이 "차별점 — 없으면 기획 반려" 인 게 힌트다.
  **판정법**: 저장을 눌렀는데 `document.querySelector('#dr-save')` 가 여전히 잡히면 안 닫힌 것이다.
  차별점을 채우고 다시 누르면 바로 저장된다. 그래서 매뉴얼 아래 "차별점을 모르겠으면 차별점 미정"
  은 **새 카드에는 못 쓴다.** 제목에서 읽히는 쪽으로 정하고 보고에 적는다.
- **이 화면에서는 `form_input` 과 `find` 가 45초 타임아웃으로 죽는다.** `javascript_tool` 은 멀쩡히 된다.
  값 넣기는 스크립트로 하고, 버튼은 진짜 클릭으로 한다. 위 "카드 하나 만드는 순서" 를 그대로 따른다.
- **생산 라인과 게시 일정은 따로 노는 목록이다.** 같은 콘텐츠가 양쪽에 **다른 제목으로** 들어가 있다.
  생산 라인은 김제조 말투("서울대 약공장 대표는 안 사는 영양제"), 게시 일정은 우리 노션 제목
  ("서울대 약사는 안사는 영양제") 을 쓴다. 게시 일정에 있다고 생산 라인에 있는 게 아니니
  **양쪽을 따로 세야 한다.** 260818 에 게시 일정에는 10건이 다 있는데 생산 라인에는 4건이 없었다.
- **게시 일정 목록은 게시판 보기로 봐야 다 나온다.** 캘린더 보기는 그 달만 보여주고 담당자도 안 보인다.
  `보기 → 게시판` 을 누르면 `tr` 로 전부 읽힌다.
- **다른 탭은 열기 전까지 카드가 DOM 에 없다.** `#view-schedule` `#view-drops` 는 `hide` 클래스가 붙어
  있고 안이 비어 있다. 탭을 진짜로 눌러야 채워진다. 전역 상태 객체는 없으니 DOM 으로 읽어야 한다.
- **보드 카드를 스크립트로 클릭하면 렌더러가 먹통이 된다.** 260818 실측이다.
  `card.click()` 도 `#btn-new` 클릭도 45초 타임아웃이 났고 그 뒤 캡처까지 안 됐다.
  **읽기는 DOM 으로, 누르기는 진짜 클릭(computer)으로 한다.** 새 화면에서는 스크롤을 한 번
  굴린 뒤에 누른다. 자세한 건 `runners/claude.md` 의 "화면이 멀쩡해 보이는데 아무 일도 안 일어날 때"
- **카드 HTML 을 통째로 읽으면 도구가 막는다.** `data-id` 가 토큰처럼 보여서 걸린다.
  제목, 배지, 담당자처럼 **필요한 값만 뽑아 읽는다**
- **제목이 노션과 다르다.** 글자로 찾으면 다 못 찾는다. 위 대응표를 쓰고, 없으면 뜻으로 맞춘다
- **노션 표에 다른 약사님 콘텐츠가 섞여 있다.** 편집 진행도의 `인플루언서` 칸을 꼭 거른다.

- **폴더 이름의 날짜는 촬영일이다.** 편집일이 아니다. 파일 수정 시각으로 판단한다
- **`보정본.mp4` 와 편집자 폴더 안 파일을 헷갈리지 마라.** 보정본은 가편집본이고
  최종본은 편집자 이름 폴더 안에 있다
- **마이박스는 크롬 익스텐션에서 차단된다.** 위 절대로 사람에게 넘긴다
- **마이박스 이름 규칙을 안 맞추면 반려된다.** 거기는 `YYMMDD 제목.mp4` 하나로 통일돼 있다.

- **차단 때문에 중복을 못 거른다.** 목록을 볼 수 없으니 이미 올라간 것을 또 모으게 된다.
  260818 에 늙크크 필수템과 오메가3 김제조 AI 영상 두 개가 그랬다.

## 묻지 말고 이렇게 한다

- **보드에 없는 콘텐츠가 있으면** 카드를 만든다. 물어보지 않는다. 담당자는 권혁찬
- **단계가 애매하면** 위 대응표에서 가까운 쪽으로 두고 보고에 적는다
- **보드가 노션보다 앞서 있으면** 그대로 둔다. 대표님이 옮긴 것이다.
  게시일이 노션보다 하루 이틀 당겨져 있는 것도 여기 해당한다. 고치지 말고 보고에 적는다
- **차별점을 모르겠으면** 제목에서 읽히는 쪽으로 정하고 보고에 적는다.
  새 카드는 `차별점 미정` 으로 두면 저장 자체가 안 된다("알려진 함정" 참고)
- **노션에서 폐기·보류한 기획**은 보드에 카드를 만들지 않는다. 보드에 올라간 적이 없으면 접을 것도 없다.
  이미 보드에 있는 것만 드랍으로 옮긴다
- **게시가 끝났는지 확실하지 않으면** 게시 완료로 넘기지 않는다. 드라이브 `업로드 완료` 폴더에 있다는 건
  정황이지 증거가 아니다. 보고에 "지연으로 남아 있음" 으로 적고 넘긴다
- **채널을 모르겠으면** 인스타 릴스로 둔다. 김주성 대표님 건은 대부분 릴스다
- 올릴 영상이 없으면 "오늘 편집분 없음" 으로 보고하고 끝낸다
