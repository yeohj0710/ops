# PDRN 리퀴드샷 발송 처리

- **부르는 말**: 발송 처리해줘, PDRN 발송, 리퀴드샷 발송, 배송 엑셀 만들어줘, 송장 확인해줘
- **런너**: claude
- **제어층**: L1 (시트·엑셀) · L3 (구글 시트·노션) · L4 (카톡 전달)
- **한 번에 걸리는 시간**: 20~40분

---

## 무엇을 만드는 업무인가

배송 폼으로 들어온 신청 중 **아직 송장이 없는 건**만 골라 오늘 날짜 발송 요청 엑셀로 만들고,
그 파일을 카카오톡 나와의 채팅으로 보낸다. 서성만 과장님께 전달할 메시지도 같이 써준다.

사람이 폰으로 받아 보고 고칠 건 고친 뒤 과장님께 넘긴다.

## 절차서는 따로 있다 — 베끼지 마라

**작업 규칙 전부가 이 파일에 있다.** 먼저 끝까지 읽고 그대로 따른다.

```
G:\내 드라이브\[제품] PDRN 리퀴드샷\발주확인 및 발송처리\agents.md
```

거기 담긴 것 — 기본 절차 10단계, 원본 시트 링크 4개, 수량 규칙(협찬 10박스·이벤트 1박스),
스마트스토어 주문 가공, 송장 대조, 중복 판단, 파일명 규칙, 최종 검증 목록.
**이 매뉴얼에 옮겨 적지 않는다.** 두 벌이 되면 어느 게 맞는지 모르게 된다.

작업 폴더도 거기다. 날짜 폴더 `YYMMDD` 와 `PDRN_리퀴드샷_발송요청_YYYYMMDD.xlsx`.

## 절차

1. **`agents.md` 를 읽는다 — L1.** 이게 1번이다. 건너뛰지 마라

2. **원본을 대조한다 — L1·L3**
   노션 `[매일매일 확인] 주문/발송 체크` 와 구글 시트 3개(협찬·사전테스트·이벤트 당첨).
   **최신 폴더 몇 개만 보지 말고** 이 폴더의 모든 날짜 폴더와 송장 파일을 재귀로 확인한다.

3. **송장 없는 건만 남긴다.** 이미 송장이 있으면 오늘 요청에서 뺀다.
   과거 송장 파일에서 찾으면 원본 시트에 먼저 반영하고 뺀다.

4. **발송 요청 엑셀을 만든다 — L1.** 열 순서·서식·검증은 전부 `agents.md` 규칙대로.
   오늘 보낼 게 없으면 **빈 폴더나 빈 파일을 만들지 마라.**

5. **카카오톡 나와의 채팅으로 보낸다 — L4** (아래 참고)

6. **과장님께 전달할 메시지 초안을 같이 준다.** 채팅에도 코드블록으로 찍는다.

## 카카오톡으로 보내기

사람이 자리에 없는 경우가 많다. 완성한 엑셀을 **나와의 채팅**으로 보내면 폰에서 바로 받는다.

- 받는 사람: **여형준** (본인). 나와의 채팅
- 보낼 것: 오늘 발송 요청 엑셀 + 요약 + 과장님 전달 메시지 초안
- 로그인이 필요하면 `자격증명/계정.md` 의 카카오톡 항목을 쓴다.
  4자리 임시 비밀번호를 물으면 그것도 거기 있다

**업무 톡방에는 절대 보내지 않는다.** 나와의 채팅 하나만이다.
보내기 직전에 **창 제목이 나와의 채팅인지 다시 확인한다.** 아니면 멈춘다.

수집기(`<DEV>/kakao-collector`)는 전송이 막혀 있다. 그건 읽기 전용 도구라 그대로 둔다.

### 과장님 전달 메시지 형태

```
서성만 과장님, PDRN 리퀴드샷 발송 요청 드립니다.

오늘 발송 8건 · 총 26박스입니다.
 · 인플루언서 협찬 2건 (20박스)
 · 팔로워 이벤트 6건 (6박스)

파일 첨부드립니다. 송장번호 나오면 회신 부탁드립니다.
```

건수·박스 수는 엑셀에서 그대로 가져온다. 지어내지 마라.

## 산출물

- `<발주확인 및 발송처리>/YYMMDD/PDRN_리퀴드샷_발송요청_YYYYMMDD.xlsx`
- 원본 구글 시트에 반영한 송장번호 (찾은 게 있으면)
- 카카오톡 나와의 채팅: 엑셀 + 요약 + 과장님 메시지 초안
- 채팅에 찍은 요약과 메시지 초안

## 완료 검사

`agents.md` 의 "최종 검증" 목록을 그대로 쓴다. 더해서 이것만 본다.

- [ ] (기계) 오늘 발송 대상이 0건이면 폴더·파일을 안 만들었다
- [ ] (사람) 카톡이 **나와의 채팅**으로 갔다. 업무 톡방이 아니다
- [ ] (사람) 요약의 건수·박스 수가 엑셀과 같다

## 알려진 함정

- **`agents.md` 를 안 읽고 시작하면 거의 틀린다.** 수량 규칙·중복 판단·파일명이 다 거기 있다
- **최신 폴더만 보면 안 된다.** 과거 송장이 다른 폴더에 있을 수 있다
- 스마트스토어 엑셀은 암호가 걸려 있다(보통 `1234`). Excel COM 으로 연다
- 16자리 주문번호를 숫자로 쓰면 정밀도가 깨진다. 텍스트 서식으로 넣는다
- 한글 경로를 스크립트에 직접 박으면 깨질 수 있다. 환경변수로 넘긴다
- `Ooznary 센텔라 PDRN 37세럼` 은 **다른 제품이다.** 리퀴드샷 발송에 넣지 마라
- 이름만 같다고 송장을 연결하지 마라. 후보가 여럿이면 `송장 확인 필요` 로 보고한다
- `v2`·`최종`·`수정본` 파일을 새로 만들지 마라. 같은 이름을 유지하고 옛 파일은 `etc` 로 백업

## 사람에게 물어야 하는 지점

- 송장 후보가 여럿이라 어느 건인지 애매할 때
- 원본 시트에 접근이 안 될 때 — 나머지만 보고 완료라고 하지 말고 알린다
- 채널별 주문 조회(스마트스토어·쿠팡·아임웹)까지 해야 하는지.
  기본은 배송 폼 처리까지다. 주문 조회는 사람이 시킬 때만 한다
