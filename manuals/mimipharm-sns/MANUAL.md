## 무엇을 만드는 업무인가

동대문 미미라인 4층 **MIMI K-beauty Care Pharmacy** 의 인스타그램 계정 **미미팜(mimipharm)** 과 언어 계정 3개를
**기획안대로 만들고 굴린다.** 어라운드팜과 달리 계정이 없던 곳이라 **계정 세팅부터** 이 매뉴얼에 들어 있다.
기획, 제작, 발행, 방문 크리에이터 공동 게시, 댓글과 DM, 월간 리포트가 갈래다.

기획안 원본은 `<드라이브>/[운영] 미미팜 인스타그램/` 의 PDF 25장인데 **PDF 텍스트 추출이 깨진다**(피그마 서브셋 폰트).
같은 폴더의 **`기획안.md`** 에 25장 전부와 260903 발표 회의 결정을 글로 옮겨 뒀다. 기획안이 필요하면 그 파일을 읽는다.

**약사 개인 계정 카드뉴스는 `manuals/card-news`, 어라운드팜은 `manuals/aroundpharm-sns` 다.** 계정 이름을 보고 고른다.

## 쉬운 설명

### 쓰는 상황

동대문 미미라인 4층 약국의 인스타그램을 9월부터 새로 엽니다. 처음에는 프로필과 하이라이트, 링크 페이지를 세팅하고,
그다음부터 주에 릴스 2편과 카드뉴스 2편을 올리고, 약국을 다녀간 해외 인플루언서 릴스를 공동 게시로 받습니다.
매달 말에 월간 리포트와 다음 달 편성표를 약국에 보냅니다.

### 시키는 말

> G드라이브 에이전트 폴더 참고해서 미미팜 인스타그램 운영 업무 해줘

세팅이 끝난 컴퓨터에서는 "미미팜 올려줘", "미미팜 공동 게시 확인해줘" 처럼 갈래를 붙여 줄여 말해도 됩니다.
갈래 없이 "미미팜 운영해줘" 라고 하면 오늘 날짜로 할 일을 스스로 정해서 합니다.

### 진행 순서

1. 노션 운영 페이지의 세팅 할 일 여섯 개 중 남은 것이 있으면 그것부터 합니다.
2. 편성표와 노션 기획안 목록을 보고 오늘 무엇이 밀렸는지 봅니다.
3. 밀린 것부터 합니다. 기획안이 없으면 쓰고, 카드뉴스가 없으면 만들고, 만든 것이 있으면 올립니다.
4. 약국을 다녀간 인플루언서가 릴스를 올렸는지 보고 공동 게시로 붙입니다.
5. 25일 이후면 다음 달 편성표와 월간 리포트를 씁니다. 약국 카톡방에 올릴 글은 초안까지만 씁니다.

### 결과물

드라이브 `[운영] 미미팜 인스타그램/` 안의 `콘텐츠/`, `편성표/`, `리포트/` 폴더와 노션 기획안 DB 상태, 인스타 프로필과 게시물입니다.

## 실행 계약

사용자가 이 업무를 호출하면 해당 갈래의 절차와 완료 검사를 한 번에 실행한다. 게시 직전에 다시 승인받지 않는다.
계정, 파일, 캡션, 비율만 확인하고 올린다. 중간 산출물만 남기고 멈추지 않는다.

멈추는 것은 다섯이다. **약국 카톡방과 DM 으로 남에게 보내는 것**(초안만), **댓글 삭제**(목록만), **매뉴얼 밖 지출**,
**새 계정이나 링크 페이지 계정 만들기**(문안과 자료까지 준비하고 사람이 만든다), **약국 확인이 필요한 가격과 재고 답변**(질문 목록으로 넘긴다).

### 콘텐츠 형식

**사람 출연 형식을 넣지 않는다.** 약사 출연, 직원 콩트, 길거리 퀴즈, 새 섭외는 굴러가지 않아서 260902 에 뺐다. 사람이 나오는 릴스는 방문 크리에이터 공동 게시(D)로만 채운다.

### 협업 창구

### P1. 다음 달 편성표를 짠다 (L1)

매달 25일 이후에 한다. 결과는 `편성표/YYYY-MM.md` 와 약국 톡방에 올릴 `편성표/YYYY-MM 안내 초안.md`.

3. 현장 촬영은 월 1회. 밤 골목 촬영은 밤 11시에서 새벽 3시 사이로 잡는다.

   ```
   | 날짜 | 요일 | 슬롯 | 형식 | 상태 |
   | 10/02 | 목 | 릴스 | A | 예정 |
   ```
5. 안내 초안에는 약국이 확인할 것(발행 직전 검토 요청, 필요한 제품 정보)을 같이 적는다.

### P2. 기획안을 쓴다 (L1, 레퍼런스 볼 때 L3)

노션 기획안 DB 에 새 페이지로 쓴다. 260907 기준 릴스 1건, 카드뉴스 2건이 사람 손으로 들어 있다. 같은 소재가 있는지 먼저 본다.

1. 형식 표에서 소재를 고른다. 이너뷰티, 약국 전용 제품(리쥬닉, 판테놀케어), 오시는 길 갈래, 환절기 순으로.

### P4. 릴스 캡션과 자막을 쓴다 (L1)

편집본이 `콘텐츠/<YYMMDDhhmm 제목 (릴스 A) (mimipharm)>/` 에 mp4 로 와 있을 때 한다. 촬영 원본은 `260903 미미라인 촬영 영상/` 처럼 운영 폴더 바로 아래 날짜 폴더에 둔다.

1. 영상을 1초에 한 장씩 잘라 직접 본다 (`manuals/caption-gen` 방법). 화면의 제품 이름, 층, 영업시간이 재료다.
2. 캡션은 브랜드 계정 톤. 첫 줄에 위치나 시간 후킹(동대문 밤시장, 새벽 5시), 본문 두세 문단, 저장 유도, 해시태그 3개 안팎(#동대문밤시장 #동대문약국 #K뷰티약국 같은 선점 키워드 포함), 링크는 "프로필 링크".
3. 자막 규칙 검수: 화면 아래 3분의 1, Pretendard, 계정명 배지 왼쪽 위, 데드존 회피. 어긋나면 `편집 비고` 에 적는다.
4. `캡션.txt`, `캡션.html`, `캡션.en.txt`, `번역 요청.md`, `고정댓글.txt`(링크 페이지 주소와 오시는 길 한 줄).
5. 노션 상태 `업로드 예정`. 약국 확인 요청 초안을 남긴다.

### P5. 올린다 (L1 고르기, L3 게시)

1. 로그인된 탭에서 본계정 피드를 받아 저장한다. 계정 숫자 id 는 프로필 HTML 의 `"profile_id":"(\d+)"`.
   ```js
   const r = await fetch("/api/v1/feed/user/<id>/?count=30", { headers: { "x-ig-app-id": "936619743392459" } }).then(r => r.json());
   JSON.stringify((r.items||[]).map(i => ({ code: i.code, taken: i.taken_at, cap: (i.caption?.text||"").split("\n")[0] })))
   ```
   새 계정이라 피드가 비어 있으면 `[]` 를 저장한다.
2. 올릴 한 편을 스크립트가 정한다. 가장 오래된 미게시 한 편이다.
   ```bash
   node "<OPS>/manuals/card-news/scripts/cardnews-next.mjs" "<피드.json>" --root "<드라이브>/[운영] 미미팜 인스타그램/콘텐츠" --account mimipharm
   ```
   mp4 가 든 폴더는 릴스, png 만 든 폴더는 카드뉴스다. 후보가 없으면 종료 코드 3.
3. **게시 화면의 계정명을 확인한다.** 쿠키 `ds_user_id` 로 `/api/v1/users/<id>/info/` 를 불러 `username` 이 `mimipharm` 인지 본다. 아니면 계정 전환(DOM 글자로 `.click()`) 뒤 다시 연다.
4. 파일을 넘긴다. `insta-file-server.mjs "<고른 폴더>"`. 카드뉴스는 `card-news` U3~U4, 릴스는 `shorts-pipeline` P6 그대로.
5. **캡션은 게시 뒤 수정 화면에서 넣는다** (card-news U4-1). `/api/v1/media/<pk>/info/` 의 `caption.text` 길이로 확인.
6. 고정 댓글을 단다.
7. 게시를 API 로 확인한 뒤 옮긴다.
   ```bash
   node "<OPS>/manuals/card-news/scripts/cardnews-done.mjs" "<고른 폴더>" --root "<드라이브>/[운영] 미미팜 인스타그램/콘텐츠" --url https://www.instagram.com/p/<코드>/
   ```
8. 노션 상태 `업로드 완료`, `편집 진행도 연결` 에 게시물 주소. 편성표 슬롯 상태 `게시`.
9. 언어 계정이 있으면 같은 편의 언어판을 같은 방법으로 올린다. 한국어 본계정을 먼저 올리고 해외 3개 계정은 일정 시간 안에 올린다. 중국어와 일본어판은 담당자가 올린다.

### P6. 방문 크리에이터 릴스를 공동 게시로 붙인다 (L1 목록, L3 수락)

1. 섭외 시트 `배정` 탭에서 약국이 미미라인이고 방문일이 지난 사람의 핸들을 모은다 (읽기만. 시트 쓰기는 `influencer-seeding` 규칙).
2. 각 핸들의 최근 릴스를 수집기(`ig-harvest.mjs`)로 받아 약국이나 미미라인이 나온 편을 찾는다. 로그인 없이 된다.
3. 인스타 알림에서 **공동 작업자 초대**가 와 있으면 수락한다 (L3). 초대가 웹 알림에 안 보이면 폰 앱에서 사람이 수락해야 한다. 수락하면 그 릴스가 약국 피드에도 같이 뜬다.
4. 초대가 없는 편은 크리에이터에게 공동 작업자 추가를 부탁하는 문안을 `리포트/공동 게시 요청 YYYY-MM-DD.md` 에 초안으로 둔다. 보내는 것은 사람(또는 중화권 담당자)이다.
5. 미미라인 자체 인플루언서 게시물 목록이 오면 같은 절차로 붙인다. 리포스트가 필요한 편은 목록에 적는다.
6. 붙인 편은 `콘텐츠/공동 게시 기록.md` 에 날짜, 핸들, 주소, 조회수를 적는다. 월간 리포트의 공동 게시물 보고가 여기서 나온다.

### P7. 댓글과 DM 을 본다 (L3)

1. 최근 게시물 전체의 댓글을 훑는다. 위치, 영업시간, 언어 대응, 정보성 질문에 답글을 단다. 언어 계정은 그 언어로. 중국어와 일본어는 담당자 몫이라 목록만 넘긴다.
2. **답하지 않는 것**: 의약품 효능 단정, 약국 확인 없는 가격과 할인, 처방약 상담. "약국에 문의" 로 돌린다.
3. 비방과 스팸은 `리포트/악플 목록 YYYY-MM-DD.md` 에 주소와 내용만. 삭제는 사람.
4. DM 은 `abilities/인스타그램.md` 규칙대로 **열기 전에 안 읽은 방 목록을 먼저 적고, 다 읽고 나서 전부 안 읽음으로 되돌린다.** 재고와 가격 문의는 약국에 확인할 질문 목록(`리포트/약국 확인 질문 YYYY-MM-DD.md`)으로, 나머지는 답장 초안으로. 보내지 않는다.
5. 자주 나오는 질문은 하이라이트 소재로 적어 둔다.

### P8. 월간 리포트를 쓴다 (L1 수집, L3 인사이트)

매월 말, 다음 달 편성표(P1)와 함께다. 결과는 `리포트/YYYY-MM 월간.md` 와 톡방 초안. 주간 리포트는 없다. 초반에는 힘을 빼라는 약국 지시가 있어 숫자만 정확히 채운다.

1. 편별 공개 지표(조회, 좋아요, 댓글, 팔로워)는 로그인 없는 수집기로. `node "<OPS>/manuals/insta-metrics/scripts/ig-harvest.mjs" --check`, 절차는 `manuals/insta-metrics/MANUAL.md`.
2. 저장, 공유, 도달, 프로필 방문, 팔로워 순증은 로그인된 본계정 인사이트 화면에서 `get_page_text` 로 옮긴다 (L3).
3. 열 칸: 콘텐츠 업로드 목록(편별 날짜, 형식, 제목, 링크) / 편별 지표(조회, 저장, 공유, 댓글, 팔로워 유입) / 공동 게시물 보고 / 팔로워 증감(4개 계정 각각) / 댓글과 DM(내용과 건수) / 월 합계(발행 편수, 조회 합계, 저장 합계, 팔로워 순증) / 형식별 순위(A~D) / 상위 3편과 이유(첫 화면, 길이, 소재) / 다국어 계정 운영 보고 / 다음 달 편성표(형식 배분, 촬영 일정, 교체 후보).
4. 숫자에 출처(수집기 `play_count` 인지 화면 표기인지)를 한 줄 적는다.
