# 힉스필드 영상 제작

- **부르는 말**: 힉스필드 영상 생성, 힉스필드로 영상 만들어줘, 영상 프롬프트 세팅, 장소 홍보영상, 제품 광고영상, 힉스필드 견적, 어라운드팜 AI 영상
- **미리 허가**: 공식 연결 점검, 무료 조회, 자료 조사, 제작안과 로컬 검토본 저장. 크레딧 사용, 구독·체험 신청, 공개 게시, 자동 생성은 포함하지 않는다.
- **런너**: either
- **제어층**: L1 → L3
- **한 번에 걸리는 시간**: 연결과 자료 상태에 따라 15~30분

## 무엇을 만드는 업무인가

장소·제품·브랜드·설명·행사·창작 영상의 자료와 목적에 맞춰 프롬프트와 제작 계획을 만든다. 어라운드팜은 적용 사례 중 하나다. 기본 예산은 **0크레딧**이다. 연결과 조회가 정상이어도 영상 생성 검증을 마쳤다고 쓰지 않는다.

새 세션에서 **"G드라이브 에이전트 폴더 참고해서 힉스필드로 ○○ 영상 생성해줘"**라고 하면 이 매뉴얼과 같은 폴더의 `WORKFLOW.md`를 읽는다([온라인 견적·전처리·생성 절차](https://github.com/yeohj0710/ops/blob/main/manuals/higgsfield-video/WORKFLOW.md)). 소재 선택과 무료 전처리까지 먼저 끝낸다. 매번 **예상 크레딧, 충전 패키지 기준 USD·원화 환산, 추가 충전 필요액**을 보여준다. 비용 한도를 이미 승인받았으면 그 범위 안에서 이어가고, 한도가 없으면 완성된 견적에 대해 한 번만 확인한다. 지금 설정 요청은 실제 생성이나 충전 승인이 아니다.

공통 진입점은 `<에이전트>/기억/영상 제작/시작.md`다. 프롬프트를 짜기 전에 같은 폴더의 `PROMPTING.md`를 읽는다([온라인 프롬프트 설계](https://github.com/yeohj0710/ops/blob/main/manuals/higgsfield-video/PROMPTING.md)). 어라운드팜 제작 사례는 `<에이전트>/기억/SNS 계정 운영/힉스필드 영상 제작.md`에 남긴다. `<에이전트>`는 기계 설정의 `drive_root` 아래 `에이전트`다. 절차 정본은 이 매뉴얼이고 드라이브 `매뉴얼/higgsfield-video/`는 사본이다.

## 절차

1. 목적과 대상, 기존 작업 ID를 확인한다. `PROMPTING.md`에 따라 실제 자료 → 한 줄 이야기 → 컷표 → 일관성 → 이미지·영상·음향 프롬프트를 설계한다. 특정 브랜드나 9:16을 기본으로 고정하지 않는다. 원본을 보존하고 무료 전처리부터 마친다.
2. 모델·길이·해상도·수량별 실시간 견적을 읽는다. 매번 **예상 크레딧, 충전 패키지 기준 USD·원화, 추가 충전 필요액**을 먼저 보고한다.
3. 비용 한도가 이미 승인됐다면 범위 안에서 진행한다. 한도가 없으면 완성된 견적에 대해 한 번 확인한다. 생성 도구가 없는 PC는 승인 뒤 공식 웹에서 재견적한다.
4. 작업 ID를 기록하고 중복 제출을 막는다. 완료 영상을 검수하고 실제 차감·환급과 환산 비용을 남긴다. 충전·구독·게시를 임의로 추가하지 않는다.
5. 컷 시간과 생성 요청 수는 `scripts/plan-check.mjs`로 확인한다. 목적별 기준은 [프롬프트 설계](https://github.com/yeohj0710/ops/blob/main/manuals/higgsfield-video/PROMPTING.md), 비용과 실행은 [견적·전처리·생성 절차](https://github.com/yeohj0710/ops/blob/main/manuals/higgsfield-video/WORKFLOW.md)를 따른다.

## 비용 기준

1. 공식 MCP 주소는 `https://mcp.higgsfield.ai/mcp`다. OAuth로 연결한다. 일반 연결에는 개발자 API 키나 브라우저 쿠키 추출이 필요 없다.
2. 공식 도움말은 MCP·CLI·자동화 생성에 크레딧을 부과하고 웹의 무료·무제한 혜택과 구분한다. 웹 구독과 개발자 API 잔액도 같은 것으로 가정하지 않는다.
3. 도구 설명에 `supports_unlim`이나 무료 체험이 있어도 생성 승인은 아니다. 계정 자격·요청 조건·실제 차감액이 모두 확인되지 않으면 실행하지 않는다. 문서와 도구가 다르면 더 제한적인 조건을 따른다.
4. **무료 크레딧도 크레딧이다.** 크레딧 소모 금지 요청에는 지급받은 잔액도 쓰지 않는다. `$0` 체험이라도 카드 등록·자동 갱신이 있으면 신청하지 않는다. 환급 행사도 먼저 비용이 나갈 수 있다.
5. 기본 설정은 검증한 조회 도구만 허용한다. 생성, 업스케일, 재생성, 분석 작업 제출, 원격 실행, 프리셋 실행, 게시 도구는 열지 않는다. 다른 유료 서비스로 우회하지 않는다.
6. Codex 사용량 초기화 크레딧은 이 업무와 별개다. 사용자의 새롭고 직접적인 '지금 초기화' 지시 없이는 사용하지 않는다.

## 연결 점검

1. **기존 설정 확인(L1).** 현재 앱의 MCP 설정에서 주소, 활성화 상태, 인증 상태를 본다. 정상인 연결을 중복 등록하지 않는다. 설정을 바꾸기 전 `<에이전트>/etc/higgsfield-setup/`에 원본을 보관한다. 비밀값은 출력하거나 공개 저장소에 넣지 않는다.
2. **공식 인증(L1 → L3).** 앱의 OAuth 로그인으로 연결한다. 이미 로그인된 계정과 연결 대상 계정을 대조한다. 비밀번호·쿠키를 파일에서 추출해 입력하지 않는다. 로그인과 구독 변경을 구분한다.
3. **조회 전용 검증(L1).** 아래 스크립트는 설정을 읽고 MCP 도구 목록을 가져온다. 모델 호출, 영상 생성, 결제, 설정 쓰기를 하지 않는다.

   ```text
   node "<OPS>/manuals/higgsfield-video/scripts/doctor.mjs"
   ```

4. 앱에서 새 연결이 안 보이면 MCP 재연결 또는 새 대화에서 확인한다. 진행 중인 다른 대화나 사용자 앱을 강제로 종료하지 않는다. 설정 저장만으로 현재 대화의 도구가 갱신됐다고 단정하지 않는다.

허용 목록은 `balance`, `transactions`, `models_explore`, `get_workflow_instructions`, `get_workflow_bundle_file`, `get_preset_instructions`, `show_generations`, `job_status`다. 새 도구를 자동 추가하지 않는다. 이름과 설명, 읽기 전용 표시를 함께 확인한다.

## 자료와 장면 준비

1. 요청 대상의 실제 자료와 프로젝트 기억을 읽는다. 어라운드팜·MIMIPharm을 요청한 경우에만 `<에이전트>/기억/SNS 계정 운영/시작.md`, 해당 제품 목록, `영상 소스 찾기.md`를 추가로 읽는다. 실제 파일과 기획안을 구분한다.
2. 진열대 디자인 시안, 제품 광고 영상, 실제 매장 촬영을 각각 표시한다. 파일명에 '샵인샵'이 있어도 약국 내부 실사라는 뜻은 아니다. 샘플 프레임을 보고 용도를 정한다.
3. 제품 이름·용기·라벨은 공식 사진을 기준으로 한다. 생성 모델에 제품과 글자를 새로 그리게 할수록 변형 위험이 커진다. 공간·카메라 움직임만 생성하고 제품 사진을 편집에서 합성하는 방법도 검토한다.
4. 실제 지점을 보여줘야 하면 해당 지점 사진이 필요하다. 사진이 없으면 '가상의 약국 진열 예시'로 기획하고 지점명·주소·실제 입점 인증을 붙이지 않는다. 게시본의 AI 연출 표시는 해당 편의 편집 기준에 반영한다.
5. 비율·길이·컷 수는 목적과 납품 채널에 맞춘다. 장소 홍보의 20초·16:9와 제품 보조 컷의 짧은 9:16은 서로 다른 제안이다. 길이·해상도·참조 수는 현재 모델에서 다시 읽는다.
6. 손·얼굴·빠른 동작·복잡한 반사가 필요하면 장면을 단순화하고 구도·길이를 조정한다. 필요한 인물과 활동을 무조건 삭제하지 않는다. 접촉·그림자·수직선·글자·공간 깊이를 검수한다.
7. 프롬프트 자동 확장이 새 물체나 과한 움직임을 추가하면 끈다. 정확한 문구·로고·자막은 원본 보존과 편집 합성을 검토한다. 4개 언어 자막은 해당 SNS 요청에만 적용한다. 음원과 실제 음성의 사용 범위를 확인한다.

## 생성이 별도로 승인된 뒤

현재 매뉴얼 호출만으로 크레딧을 쓰지 않는다. 이번 작업의 대상·수량과 비용 한도를 사용자가 지정했거나, 완성된 견적을 승인한 경우에만 실행한다. 크레딧 또는 금액 중 하나의 한도를 받을 수 있다. 같은 범위의 승인된 한도 안에서는 다시 묻지 않는다. 지출 금지 지시가 남아 있으면 그 지시가 우선이다.

현재 PC의 MCP는 조회 도구만 노출한다. 승인 뒤에도 생성 도구가 없다면 로그인된 공식 웹에서 같은 모델·입력·옵션의 견적을 다시 확인하고 실행한다. 웹 견적이 승인 상한보다 높으면 제출하지 않는다. 조회 제한을 몰래 풀거나 전체 도구 허용으로 바꾸지 않는다. 이 경로는 웹 조작이 가능하고 계정 권한이 있을 때 쓴다. 실제 영상 생성은 아직 시험하지 않았다.

1. 모델 제약, 정확한 견적, 업로드할 원본, 자동 공개 여부를 확인한다. 예산이 불명확하면 생성 버튼을 누르지 않는다.
2. 승인된 생성 요청 목록대로 제출한다. 한 편을 여러 클립으로 만들면 실제 요청 수와 생성 길이를 견적에 넣는다. 제출 직후 작업 ID를 저장한다. 시간 초과가 나면 먼저 작업 내역을 확인한다. 같은 요청을 다시 제출하지 않는다.
3. 서버의 다음 확인 시각을 따른다. 초 단위 반복 확인을 하지 않는다. 기다리는 작업만 남으면 기존 장시간 작업 규칙을 적용한다.
4. 시작·중간·끝 프레임과 실제 재생을 본다. 제품 크기·라벨·개수·배치가 바뀌거나 바닥에서 뜨면 실패로 분류한다. 실패작을 자동 재생성하지 않는다.
5. 승인된 클립을 편집하고 결과, 실제 차감액, 충전 기준 환산액을 기록한다. 동시 작업이 있으면 잔액 차이를 이번 작업 비용으로 단정하지 말고 작업 ID별 거래를 대조한다. SNS 게시와 외부 전달은 별도 요청과 기존 게시 매뉴얼을 따른다.

## 알려진 함정

- **웹은 로그인됐는데 OAuth에서 로그인 화면이 다시 나옴**: 같은 브라우저의 기존 계정을 대조하고 정상 SSO를 진행한다. 다른 계정을 만들지 않는다.
- **로컬 콜백이 `ERR_BLOCKED_BY_CLIENT`로 표시됨**: 브라우저 보안을 끄지 않는다. 클라이언트가 공식 제공하는 수동 콜백 입력을 쓴다. Codex의 `--no-browser` 흐름은 이를 지원한다. 콜백 코드는 기록·공유하지 않는다.
- **연결 성공인데 도구가 0개**: 빈 허용 배열이면 모두 가려진다. 인증 실패로 단정하지 말고 서버의 도구 이름과 대조한다.
- **읽기 전용 표시만 믿음**: 설명과 기능도 확인한다. 원격 셸과 임의 앱 실행은 읽기 목록에 넣지 않는다.
- **무료 체험·무제한 문구**: 크레딧 차감 0 보장이 아니며 자동 갱신 조건이 있을 수 있다. 신청과 생성을 분리한다.
- **제작안만 있고 생성 결과가 없음**: '제작 준비 완료, 생성 품질 미검증'으로 적는다. 시험하지 않은 화질·자연스러움을 보장하지 않는다.

## 완료 조건

- 공식 주소와 OAuth 연결 상태를 확인했다.
- 조회 허용 목록에 생성·결제·실행 도구가 없다.
- 자료 위치, 직접 본 프레임, 미확인 범위를 제작안에 남겼다.
- 생성 요청 수와 작업 비용을 기록했다. 생성하지 않았다면 0건으로 적었다.
- 다음 실행에 쓸 프롬프트와 검수 기준을 저장했다.
- 목적에 맞춘 비율·길이·컷표·음향을 설계했고, 특정 브랜드의 규칙을 다른 영상에 강제하지 않았다.
- 최종 타임라인과 실제 생성 길이·요청 수·참조 한도를 대조했다.
- 견적에 전처리·이미지 생성·영상·업스케일·오디오의 비용을 빠짐없이 반영했다. 하지 않는 단계는 제외 이유를 적었다.
- 예상 크레딧과 충전 기준 USD·원화, 기준 패키지·환율·확인 시각, 세금·수수료 포함 여부를 밝혔다.
- 실제 생성했다면 결과 파일과 실제 차감·환급을 저장했다. 견적만 만든 상태를 영상 완성으로 표시하지 않았다.
- 기존 사용자 탭은 남기고 이번에 연 탭만 닫았다.
