# 쇼츠 소재 리필

- **부르는 말**: 소재 채워줘, 쇼츠 소재 리필, 소재 보충해줘, 소재큐 채워줘, 잘된 거 보고 소재 만들어줘, 재고 확인해줘
- **미리 허가**: 없음. 소재 파일만 만들고 돈을 안 쓴다
- **런너**: claude
- **제어층**: L1 만 쓴다. 로그인도 화면 조작도 필요 없다
- **한 번에 걸리는 시간**: 전략 뽑기 2분, 팩 쓰기 채널당 25분 안팎

---

## 무엇을 만드는 업무인가

`shorts-pipeline` 이 하루 한 편씩 먹어 치우는 소재 재고를 다시 채운다.
끝나면 `<채널> 소재/` 폴더에 새 팩 JSON 이 들어가 있고 검사 다섯 개가 그 팩들을 통과시킨다.

**판정은 팔로우로 한다.** 조회수로 고르면 정반대 결론이 나온다. 실측으로 확인했다.

| 편 | 조회 | 팔로우 | 전환 |
| --- | --- | --- | --- |
| 안약 넣을 때 대부분 잘못하고 있는 것 4 | 62.8만 | 86 | 0.014% |
| 무릎 허리 깎아먹는 생활 습관 7가지 | 21.6만 | 115 | 0.053% |

조회수 3분의 1인 편이 팔로우는 더 데려왔다. 채널을 키우는 것은 팔로우다.
조회수는 그날 하루 숫자고 팔로우는 다음 편의 시작 조회수다.

## 쉬운 설명

### 쓰는 상황

쇼츠 업로드는 매일 도는데 소재는 유한합니다. 재고가 열흘치 밑으로 내려가면 채워야 합니다.
채울 때 아무거나 쓰면 조회수는 나와도 팔로워가 안 늘어서, 지금까지 올린 것 중
**팔로우를 실제로 데려온 것**을 먼저 확인하고 씁니다.

### 시키는 말

"소재 채워줘" 한 마디면 됩니다. 채널을 정해 주려면 "하루건강약사 소재 채워줘" 라고 합니다.
재고만 궁금하면 "재고 확인해줘" 라고 하면 세기만 하고 멈춥니다.

### 진행 순서

재고를 세고, 어떤 영상이 팔로워를 데려왔는지 뽑고, 그 결대로 새 주제를 잡고,
이미 올린 것과 겹치는지 보고, 팩을 써서 넣고, 검사 다섯 개를 돌립니다.

### 결과물

`하루건강약사 소재/` `건강장수비결 소재/` 폴더에 새 소재 파일이 들어갑니다.
그리고 무엇이 팔로워를 데려왔는지 정리한 전략표가 작업 폴더에 남습니다.

## 실행 계약

사용자가 이 업무를 호출하면 이 매뉴얼의 절차와 완료 검사를 한 번에 실행한다.
재고를 세고 끝내지 마라. **재고가 기준 밑이면 채우는 것까지가 이 업무다.**
주제를 사람에게 물어보지 않는다. 실측과 겹침 검사로 정하고, 무엇을 왜 골랐는지 보고에 적는다.

이 업무는 돈을 쓰지 않는다. 유료 호출은 `shorts-pipeline` 이 팩을 소비할 때 일어난다.
여기서는 파일만 만든다. 그래서 되돌리기가 쉽고, 멈출 이유가 거의 없다.

## 준비물

- 인터넷. 로그인은 필요 없다. 지표는 공개된 JSON 하나로 받는다
- `<DEV>/n8n-youtube-shorts-automation` 저장소. n8n 서버는 안 떠 있어도 된다
- 규격은 그 저장소의 `AGENTS.md` 가 원본이다. **여기에 자릿수를 옮겨 적지 마라.**
  바뀌면 저쪽만 고치기 때문에, 옮겨 적은 숫자는 반드시 낡는다

## 절차

### P1. 재고를 센다 (L1)

```bash
node "<OPS>/manuals/shorts-pipeline/scripts/topic-count.mjs"
```

**소진 속도는 채널당 하루 한 편이다.** 나온 수가 곧 남은 날짜다.
**열흘 밑으로 내려간 채널을 채운다.** 두 채널 다 밑이면 둘 다 채운다.

파일 수를 그냥 세지 마라. `LOCKED_SOURCE_PACK=1` 이 붙은 파일은 본편이 안 쓴다.
이유는 `shorts-pipeline` 매뉴얼 P1 에 있다.

### P2. 팔로우 전환 전략을 뽑는다 (L1)

```bash
node "<OPS>/manuals/shorts-refill/scripts/follow-strategy.mjs" --out "<OPS>/work/<taskId>/전략.md"
```

릴스 인사이트 랩이 화면 녹화를 데이터화해 둔 공개 JSON 을 받아 한 장으로 줄인다.
**로그인도 브라우저도 필요 없다.** 인스타를 긁던 옛 절차는 조회수밖에 못 줘서 버렸다.

나온 `전략.md` 를 읽는다. **1.5MB 짜리 원본 JSON 을 읽지 마라.** 이 파일이 그걸 줄인 것이다.

읽을 것 넷이다.

| 절 | 무엇에 쓰나 |
| --- | --- |
| 팔로우를 데려온 편 | **여기 있는 결을 따라간다** |
| 팔로우가 안 붙은 편 | 조회수만 나온 것들. 여기 결은 피한다 |
| 회로별 | 본편 카드가 레퍼런스보다 낮으면 형식 문제다 |
| 항목 수별 | 회로와 얽혀 있으니 단정하지 마라 |

**다른 계정 표는 기본으로 안 나온다.** 자료에 실제 약사 계정이 같이 들어 있지만
하루건강약사는 AI 크리에이터라 그쪽 소재가 옮겨지지 않는다. 아래 "공략점" 을 보라.

### P3. 재고와 큐 위생을 본다 (L1)

```bash
node "<OPS>/manuals/shorts-refill/scripts/analyze-performance.mjs" "<OPS>/work/<taskId>/insta-plays.tsv"
```

실측 TSV 가 없으면 이 단계는 건너뛰어도 된다. **다만 아래 하나는 반드시 확인한다.**

```bash
node "<OPS>/manuals/shorts-refill/scripts/analyze-performance.mjs" --stock-only
```

`research/queue` 에 발행하고 안 지운 팩이 남아 있으면 지운다.
두면 `verify-stockpile-titles-unpublished` 가 상시 실패한다.

### P4. 주제를 잡는다

순서를 지킨다. **생활에서 주제를 먼저 잡고, 중복검사를 통과시키고, 그 다음에 내용을 채운다.**
근거를 찾으러 논문에 가지 마라. 논문에서 주제가 나오면 접근성이 폭락한다.
근거는 주제를 고른 **다음에**, 위험한 행만 확인한다(P6).

거르는 기준 넷이다. 아래 "공략점" 절이 이 기준의 지금 값이다.

1. **팔로우를 데려온 결에서 고른다.** 조회수만 큰 결은 안 쓴다
2. **재고와 최근 발행에 있는 영역은 피한다.** 한 영역에 두 개 이상 쏠리면 좁아진 것이다
3. **행마다 가져갈 것이 있어야 한다.** 55세가 읽고 "그건 나도 알지" 하면 그 주제는 버린다
4. **틀리면 사람이 다치는 주제는 교과서 표준만 쓴다.** 확인이 안 되면 그 행을 버린다

### P5. 제목 중복검사를 먼저 통과시킨다 (L1)

내용을 채우기 전에 제목만으로 먼저 건다.

```bash
node ./scripts/check-topic-title-availability.mjs "제목 1" "제목 2"
```

**걸렸다고 제목을 비틀어 통과시키지 마라.** 제목은 항목 목록을 그대로 설명해야 한다.
검사에 걸리면 주제를 바꾼다.

이 검사는 제목만 본다. 같은 이야기를 다른 제목으로 쓰면 못 잡는다. 그건 P6 이 잡는다.

### P6. 팩을 쓰고 검사 다섯 개를 통과시킨다 (L1)

규격은 `<DEV>/n8n-youtube-shorts-automation/AGENTS.md` 의 `New-Pack Staging Checklist` 를
**그 자리에서 읽고** 따른다. 자릿수와 문장꼴이 거기 있다.

팩 파일은 `<채널> 소재/<번호>-<영문키>.json` 으로 넣는다. 번호는 그 폴더에서 안 쓴 다음 번호다.
`research/queue/<채널>/` 에도 같은 파일을 넣는다. 검증 스크립트가 그쪽을 본다.

**`notes` 에 두 가지를 적는다.** 왜 이 주제를 골랐는지(전략 근거), 그리고
위험한 행이 무엇에 기대어 쓴 것인지(사실 근거). 아래 검사가 뒤엣것을 본다.

```bash
node ./scripts/verify-queued-packs-pass-gate.mjs
```

```bash
node ./scripts/verify-queued-topics-are-fresh.mjs
```

```bash
node ./scripts/verify-stockpile-titles-unpublished.mjs
```

```bash
node "<OPS>/manuals/shorts-refill/scripts/check-claims.mjs"
```

앞 셋은 모양과 겹침을 본다. 넷째가 **틀리면 사람이 다치는 주장**을 골라 근거를 적었는지 본다.
약 이름, 병 이름, 용량, 응급, 기관 이름, 숫자가 붙은 행이 걸린다.

**근거를 못 대면 그 행을 버린다.** 숫자를 지어내지 마라. 항목이 모자라면 주제를 바꾼다.
이 검사는 근거를 적었는지만 본다. 내용이 맞는지는 마지막에 사람이 통독해서 본다.

### P7. 공략점과 실측을 매뉴얼에 반영하고 커밋한다

`전략.md` 가 지난 회차와 달라졌으면 아래 "공략점" 을 고쳐 쓴다.
그리고 커밋하고 push 한다. 소재 팩은 n8n 저장소, 매뉴얼은 ops 저장소다.

## 공략점

**마지막 실측 260825. 하루건강약사 51편, 총 조회 681만, 총 팔로우 1,732명.**
회차마다 P2 를 돌려 고쳐 쓴다. 아래는 규칙이 아니라 이번 달 성적표다.

### 다른 계정과 견주지 않는다

같은 자료에 제이약사, 제씨약사, 김제조, 오약이 같이 들어 있고 전환율도 훨씬 높다.
**그 표로 전략을 세우지 마라.** 그 넷은 얼굴과 자격이 있는 실제 약사고
하루건강약사는 AI 크리에이터다. 그쪽 상위 편은 이런 것들이다.

- 약사들이 쓰는 약과 안 쓰는 약
- 약사가 진짜 써보고 고른 내돈내산
- 서울대 약사는 안 사는 영양제

전부 **사람이 있어야 성립하는 소재**다. 옮겨 오면 못 지킬 약속을 하게 된다.
"제가 써봤는데", "우리 약국에서는", "제 환자분이" 같은 말은 이 계정에서 쓰지 않는다.
전환율 절대값도 계정 성격을 타므로, **하루건강약사 안에서의 순위만** 쓴다.

### 가르는 축 하나: 평생 들고 갈 것인가, 오늘 한 번 고치면 끝인가

51편을 팔로우 전환으로 줄 세우면 위아래가 이 하나로 갈린다.
조회수는 놀람이 만들고 **팔로우는 기대가 만든다.** 놀라기만 한 사람은 보고 지나간다.

### 팔로우를 데려온 결

| 결 | 실측 | 왜 팔로우가 붙나 |
| --- | --- | --- |
| 오래 걸리는 몸 관리 | 무릎 허리 습관 0.053%, 걷기 습관 0.040%, 장수 운동 0.039% | 오늘 한 번으로 안 끝난다. 계속 들어야 한다 |
| 매번 다시 쓰는 부엌 기술 | 냉동실 0.050%, 아침 과일 0.044%, 집밥 한 끗 0.041% | 장 볼 때마다 또 쓴다 |
| 나이 드는 태도와 관계 | 품위 있게 나이 드는 습관 0.048%, 대화 점검 0.047%, 60 이후 관계 0.037% | 답이 없는 주제라 다음 편이 궁금하다 |
| 먹고 사는 것의 판단 기준 | 돈 쓰는 순서 0.038%, 영양제 먹는 시간 0.035%, 영양제 조합 0.033% | 기준은 한 번 들어서 안 끝난다 |

### 팔로우가 안 붙은 결

| 결 | 실측 | 왜 안 붙나 |
| --- | --- | --- |
| 한 번 배우면 끝나는 교정 | 안약 0.014%(62.8만 조회), 밤 화장실 0.008%, 아침 첫 30분 0.005% | 배웠으니 이 계정이 더 필요 없다 |
| 겁주는 경고와 몸 신호 | 심장 밤새 0.004%, 손톱 변화 0.009%, 물 부족 신호 0.009% | 무섭지만 다시 볼 일이 없다 |
| 한 번 사면 끝나는 구매 판단 | 같은 값이면 0.010%, 살림살이 교체 0.012% | 사고 나면 볼 이유가 사라진다 |

**안약 편이 이 축을 제일 잘 보여 준다.** 62.8만 명이 봤는데 팔로우는 86명이다.
좋은 정보였고 조회수도 터졌지만, 배우고 나면 이 계정에 볼일이 없어진다.

### 주제를 잡을 때 스스로 묻는 것

1. **이걸 본 사람이 다음 달에도 이 계정이 필요한가.** 아니면 결을 바꾼다
2. **답이 하나로 끝나는가.** 끝나면 조회수 소재고 팔로우 소재가 아니다
3. **사람이 있어야 성립하는 말이 들어갔는가.** 들어갔으면 뺀다

### 형식은 원인이 아니다

| 갈래 | 편 | 합산 전환 | 중앙 전환 |
| --- | --- | --- | --- |
| 본편 카드 4항목 | 24 | 0.020% | 0.018% |
| 레퍼런스와 옛 편 | 27 | 0.029% | 0.029% |
| 항목 4개 이하 | 19 | 0.019% | 0.017% |
| 항목 6개 이상 | 18 | 0.034% | 0.030% |

숫자만 보면 항목을 늘리면 될 것 같지만 **아니다.**
7개짜리 `50대 이후, 자기 전에 무심코 반복하는 밤 습관 7` 이 0.011% 로 바닥권이고,
4개짜리 냉동실 편이 0.050% 로 2위다. 6개 이상이 높은 것은 그쪽이 대부분
레퍼런스 카드라서 생긴 겹침이다. **결이 정하지 항목 수가 정하지 않는다.**

본편이 4개인 것은 세로 공간 때문이다. 늘리려면 카드 레이아웃을 먼저 고쳐야 하고
발행 회로 일곱 개가 같이 바뀐다. **그건 사람이 정할 일이다.** 지금은 4개를 지킨다.

## 알려진 함정

- **다른 계정 표를 보고 전략을 세우면 못 지킬 약속을 하게 된다.** 260825 에 한 번 그렇게 썼다가
  되돌렸다. 자료에 실제 약사 계정 넷이 같이 들어 있고 전환율이 4배에서 11배 높은데,
  그쪽이 이기는 소재는 "내가 써봤다", "우리 약국에서" 처럼 **사람이 있어야 성립하는 것**이다.
  하루건강약사는 AI 크리에이터라 그 말을 쓸 수 없다. `follow-strategy.mjs` 는 그래서
  계정 표를 기본으로 안 낸다. 굳이 보려면 `--compare-accounts` 를 붙이되 전략에는 쓰지 마라
- **조회수로 판정하면 정반대 결론이 나온다.** 260825 에 재생수로 한 번 뽑았다가 다시 했다.
  안약 편이 재생수 기준으로는 2위였는데 팔로우 기준으로는 밑에서 3등이었다.
  **재생수는 반복 재생을 세고, 놀란 사람도 센다.** 판정은 팔로우로 한다
- **지표는 화면 녹화를 데이터화한 것이라 새 편이 바로 안 들어온다.** 최근에 올린 편은
  전략표에 없다. 없다고 성적이 나쁜 게 아니다. 자료를 다시 만들어야 들어온다
- **한 릴스가 두 화면으로 두 번 잡힌다.** 릴스 인사이트와 게시물 인사이트다.
  합칠 때 팔로우가 큰 쪽을 남긴다. 작은 쪽은 화면을 덜 내린 컷이다
- **`research/queue` 를 재고로 세지 마라.** 거기는 사본이고, 발행하고 안 지운 팩이 쌓인다.
  260825 에 실제 재고 15건이 26건으로 부풀어 보였다. 원장은 `<채널> 소재/` 폴더다
- **게이트가 `사이` 를 주격조사로 읽는다.** `card_name` 이 `사이` 로 이어지고 `기` 로 끝나면
  `broken_nominalization` 으로 반려한다. 검사식이 `[가-힣](이|가) ... 기$` 라 `사이 ` 의 `이` 가
  걸리는데, 예외 목록에 `없이 같이 높이 많이 깊이` 만 있고 `사이` 가 없다.
  `나이` `차이` `아이` 도 같은 꼴이다. **문장이 멀쩡하면 게이트 탓이니 말을 바꿔 우회한다.**
  예외 목록을 고치려면 `install-shared-content-quality-gate.mjs` 세 군데를 같이 고치고
  `simplify-legacy-editorial-flow.mjs` 를 반드시 뒤에 다시 돌려야 한다. 리필하다 하지 마라
- **다른 세션이 같은 시간에 파이프라인을 돌린다.** 260825 에 검사 도중 에어컨 편이 발행돼
  큐 사본이 새로 고아가 됐다. **검사가 갑자기 걸리면 P3 을 다시 돌려 치울 것을 다시 본다**
- **거부된 팩을 `사용완료` 로 옮기지 마라.** 중복검사가 발행된 것으로 보고 제목을 영영 막는다.
  `보류` 폴더로 옮긴다

## 사람에게 물어야 하는 지점

이 업무에는 거의 없다. 파일만 만들고 돈을 안 쓴다.

- 재고가 열흘치 밑인데 두 채널 다 채우면 시간이 오래 걸릴 때, 한 채널만 하고 나머지는 보고에 적는다.
  묻지 않는다
- 실측 결과가 이 매뉴얼의 "공략점" 과 정면으로 어긋나면, 고쳐 쓰고 보고에 적는다. 묻지 않는다
- **카드 레이아웃을 바꿔 항목 수를 늘리는 것은 묻는다.** 이 업무 밖이고, 발행 회로 일곱 개가
  같이 바뀐다
