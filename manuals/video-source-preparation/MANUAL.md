# 편집자 전달용 영상 소스 정리

- **부르는 말**: 영상 소스 정리, 컷편집 소스 준비, 컷 앞뒤 여유, 타이트한 컷 복구
- **미리 허가**: 지정한 작업 폴더의 소스 분류, 원본을 보존한 컷 재추출과 교체, 전달용 링크 공유 설정. 메일 발송과 원본 삭제는 포함하지 않는다.
- **런너**: codex
- **제어층**: L1 → L3
- **한 번에 걸리는 시간**: 파일 수와 원본 다운로드에 따라 수십 분 이상

## 목적

편집자가 길이와 템포를 직접 정할 수 있도록 여유 있는 컷편집 소스와 전체 길이 영상을 제공한다. 완성 영상에 맞춘 짧은 컷을 소스로 전달하지 않는다.

## 준비물

- 사용자가 지정한 채널 작업 폴더와 원본 영상.
- 기획안, 기존 컷과 원본의 대응표 및 시작·종료 시각. 대응이 불확실하면 추측해서 덮어쓰지 않는다.

## 절차

1. **원본과 컷 연결 (L1)**
   기존 처리 기록으로 각 컷의 원본 및 추출 구간을 확인한다. 새 작업의 계획·로그·백업은 `<작업 폴더>/etc/`에 둔다. 기존 컷도 교체 전에 백업한다.

2. **편집 여유 확보 (L1)**
   필요한 장면 시작 전과 끝 후에 각각 기본 3초를 추가한다. 3초는 최소 작업 기준이며 최대 길이가 아니다. 원본 시작·끝 때문에 확보하지 못하면 기록한다.
   대사는 질문·답변 또는 문장 전체를 살린다. 3초를 추가한 경계가 말하는 중이면 앞의 발화 시작 전과 뒤의 발화 종료 후까지 더 넓힌다. 같은 답변을 단어·호흡마다 쪼개지 않는다.
   무음 탐지는 경계 후보를 찾는 보조 수단이다. 침묵이 곧 문장 끝이라는 보장은 없으므로 전사나 청취로 맥락을 확인한다. 확인할 수 없으면 해당 발화 전체 또는 전체 길이 영상을 제공하고, 문장 검수를 마쳤다고 보고하지 않는다.
   매장·제품 영상은 카메라 이동이나 제품 동작의 시작과 끝을 보존한다. 인접 컷의 구간이 겹쳐도 허용한다. 원본에 없는 여유를 정지 화면·반복 프레임으로 만들어내지 않는다.

3. **폴더와 음성 처리 (L1)**
   `소스/원본 영상`과 `소스/컷편집 영상 (선택 사용)`으로 구분한다. 불필요한 번호나 `남은 소스/전체 원본` 중첩은 만들지 않는다.
   미미팜은 외부 전달 영상에서 음성 트랙을 제거한다. 전체 길이 무음 영상은 `소스/원본 영상 (무음)`에 둔다. 음성 원본과 백업은 링크로 접근할 수 없는 내부 `etc/`에 보관하고, 공개 폴더에 원본 바로가기를 남기지 않는다. `여형준` 폴더도 내부 전용이다.

4. **검사 후 교체 (L1)**
   임시 출력의 재생 길이, 앞뒤 확보 구간, 해상도, 회전, 색상 정보, 영상 디코딩 및 필요한 음성 유무를 검사한다. 음성을 유지하는 컷은 대사 경계도 확인한다. 스트림 복사는 키프레임 때문에 요청한 시각과 실제 경계가 다를 수 있으므로 경계 검증 없이 정확한 컷이라고 보고하지 않는다.
   검증에 통과한 파일만 기존 이름으로 교체한다. 원본·기존 컷·새 컷의 대응 기록을 유지하고 안내문의 구간 정보도 맞춘다.

5. **외부 전달 확인 (L1 → L3)**
   읽기 자료는 링크가 있는 사용자 모두 읽기, 작업물 업로드 폴더는 링크가 있는 사용자 모두 편집으로 설정한다. 내부 작업·음성 원본·백업은 예외로 접근을 제한한다. 세부 절차는 `<OPS>/abilities/구글드라이브.md`를 따른다.
   편집자에게 컷편집 영상은 작업 편의를 위해 준비한 선택 자료이며 전체 길이 영상도 사용할 수 있다고 안내한다. 작업물은 `소스` 옆에 본인 이름 폴더를 만들어 올리도록 안내한다. 메일은 별도 발송 지시가 있을 때만 보낸다.

## 완료 검사

- 모든 대상 컷의 원본과 시간 구간이 확인되고, 누락·실패가 기록되었는가.
- 앞뒤 기본 3초가 확보되었으며 예외가 원본 길이 때문인지 확인했는가.
- 대사와 동작이 중간에 끊기지 않는지 검수했는가. 자동 검사만 수행했으면 그 한계를 명시했는가.
- 미미팜 외부 전달 영상의 음성 트랙이 0개인가.
- 원본·기존 컷 백업이 남고, 내부 폴더와 음성 원본에 공개 링크로 접근할 수 없는가.
- 검증 결과·교체 수·남은 작업을 기록하고 실제 처리 범위만 보고했는가.

## 알려진 함정

- 완성본 템포로 소스를 짧게 자르면 편집자가 대사와 전환을 조절할 수 없다. 소스 추출과 완성본 컷편집을 구분한다.
- 폴더명 변경 후 기존 처리 기록의 경로가 낡을 수 있다. 원본 식별자와 파일 정보를 확인해 다시 연결한다.
- 무음 판정은 문장 의미를 판단하지 못한다. 자동으로 넓힌 것과 대사 검수를 마친 것을 구분한다.
- 대괄호가 있는 경로는 셸의 와일드카드로 해석될 수 있다. 문자 그대로 경로를 취급하는 방법을 사용한다.
