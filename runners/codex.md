# Codex 런너 — 제어층 대응표

매뉴얼은 "L3 으로 카페24 관리자를 연다" 처럼 **추상으로** 적혀 있다.
그걸 Codex 세션에서 실제로 어떤 도구로 하는지가 여기 있다.
도구가 바뀌면 **이 파일만** 고친다. 매뉴얼은 안 건드린다.

---

## 맡는 일

**길고 반복되는 것.** 수백 건 수집, 대량 분류, 며칠 도는 조사 루프, 밤새 도는 빌드.
`gpt-5.6-luna` `xhigh` 로 한 달 내내 돌려도 된다.

사람이 옆에서 봐야 하는 짧은 판단 작업은 Claude 에게 넘긴다.

---

## 이 기계의 Codex 설정

`~/.codex/config.toml` 기준.

- `approval_policy = "never"`, `sandbox_mode = "danger-full-access"` — 사람 승인 없이 돈다.
  **그래서 되돌릴 수 없는 일에 더 조심해야 한다.** 아래 "하지 않는 것" 을 지켜라.
- 브라우저 백엔드 두 개가 다 있다: `chrome` (로그인된 진짜 크롬), `iab` (인앱 브라우저).
- 컴퓨터 제어 플러그인이 켜져 있다.

## L1 — 명령어·API·스크립트

셸을 직접 쓴다. 이 기계는 Windows 다.

- **루프 작업은 되도록 전부 L1 로 짜라.** 화면을 안 쓰면 여러 개가 동시에 돌고, 며칠을 버틴다.
  화면 제어가 섞인 루프는 하루를 못 넘긴다.
- PowerShell 로 소스 파일을 고쳐 쓰지 마라. 한글이 깨진다. 치환은 node 로 한다.
- PowerShell 에서 `$ErrorActionPreference = "Stop"` 과 네이티브 명령을 같이 쓰면
  stderr 한 줄에 스크립트가 죽는다. `2>&1` 로 받아 종료코드로만 판정해라.

## L2 — 인앱 브라우저 (`iab` 백엔드)

로그인 없는 화면 읽기, 배포 결과 확인, 공개 페이지 수집.
세션이 격리돼 있어 로그인 상태를 안 건드린다. **가능하면 L3 보다 이쪽을 먼저 쓴다.**

## L3 — 크롬 (`chrome` 백엔드)

이미 로그인된 세션이 필요한 곳 — 카페24 관리자, 인스타그램, Figma, 노션.

- 컴퓨터 제어로 크롬을 만지지 마라. 브라우저 일은 이 층이 정답이다.

### 팝업·새 창은 탭 목록에 안 나온다

실측 결과 `window.open` 팝업도 `target="_blank"` 새 탭도 잡히지 않는다. 그룹 밖에 생긴다.
헤매지 말고 **주소를 가로채서 내가 관리하는 탭에서 연다.**

누르기 전에 이걸 심는다.

```js
window.__opened = [];
const _open = window.open;
window.open = function(u, ...r){ if(u) window.__opened.push(String(u)); return _open.call(window, u, ...r); };
document.addEventListener('click', e => {
  const a = e.target.closest && e.target.closest('a[target="_blank"]');
  if (a && a.href) window.__opened.push(a.href);
}, true);
```

버튼을 누르고 `window.__opened` 를 읽어 그 주소로 이동한다. 그러면 만질 수 있다.
폼만 채우면 되는 팝업은 아예 같은 탭에서 열어도 된다 (`window.open = u => location.href = u`).
**OAuth·결제 인증창에는 쓰지 마라** — 부모 창에 결과를 돌려주는 구조라 깨진다.

브라우저 밖 창(파일 선택창, 공동인증서, ActiveX 결제창)은 이 층으로 못 만진다. 그때만 사람을 부른다.

## L4 — 컴퓨터 제어

브라우저 밖 프로그램 — 한글, PowerPoint, 카톡, 탐색기.

- 키를 보내기 전에 **앞에 있는 창이 맞는지 캡처로 확인한다.** 확인 없이 보내면 엉뚱한 창에 들어간다.
- HWP 를 COM 으로 변환하면 사람이 치던 타이핑을 뺏어간다. 창을 숨겨도 소용없다.
  별도 데스크톱에서 돌리는 런처를 쓴다.
- 좌표를 믿지 마라. 화면 배율이 바뀌면 다른 데를 누른다.

## 루프로 돌 때

`START.md` 를 시작 프롬프트로 받는다. 규칙은 그쪽에 있다. 핵심만 다시 적으면:

- 태스크가 끝나면 보고하지 말고 **바로 다음을 뽑는다.** "계속할까요" 금지.
- 한 태스크에 갇히지 마라. 예산을 넘기면 거기까지 적고 `block` 으로 끝낸다.
- `tasks/` 폴더를 통째로 읽지 마라. 필요한 건 `next` 출력에 다 들어 있다.
  원장을 통으로 읽으면 컨텍스트가 터져 며칠 안에 죽는다.

## 준비는 직접 한다 — 사람 시키지 마라

사람이 원격에 있는 경우가 많다. "크롬 띄우고 다시 말해주세요" 같은 말은 **작업을 못 하게 만든다.**

| 막힌 것 | 사람에게 묻지 말고 이렇게 |
| --- | --- |
| 크롬이 안 떠 있다 | 직접 띄운다. 3~5초 기다렸다가 다시 붙는다 |
| 탭이 없다 | 새 탭을 만들고 이동한다 |
| 개발 서버가 안 돈다 | 띄운다 |
| 폴더가 없다 / 저장소가 낡았다 | 만들고 `git pull` 한다 |

```
"C:\Program Files\Google\Chrome\Application\chrome.exe"
```

떠 있는지 확인: `tasklist /FI "IMAGENAME eq chrome.exe" /NH`

**두 번까지는 스스로 되살려 본다.** 그래도 안 되면 무엇을 시도했고 무엇이 막혔는지 적고 넘어간다.
루프 중이면 `block` 으로 적고 다음 태스크를 뽑는다 — 사람을 기다리며 멈춰 있지 마라.

사람이 필요한 건 **권한이 걸린 것**뿐이다 — 로그인 만료, 결제수단 미등록, 되돌릴 수 없는 버튼.

## 하지 않는 것

승인 없이 도는 설정이라 이 목록이 유일한 제동이다.

- 돈 보내기·주문·거래 실행
- 메시지·메일·DM 을 사람 확인 없이 보내기
- 공개 게시(SNS 업로드, 배포된 사이트에 글 올리기)를 사람 확인 없이 하기
- 데이터 영구 삭제, 계정 설정 변경, 약관 동의
- 비밀번호·카드번호·주민번호 입력
- 유료 API 대량 호출 — 예상 비용을 먼저 말하고 사람이 켠다
