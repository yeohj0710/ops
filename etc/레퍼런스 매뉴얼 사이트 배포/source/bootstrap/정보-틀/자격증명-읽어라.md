# 자격증명 두는 법

이 폴더(`자격증명/`)에는 **스크립트가 읽는 키만** 둔다. 사람이 로그인 창에 치는 비밀번호는 안 둔다.

## 둘의 차이

| | API 키 | 로그인 비밀번호 |
| --- | --- | --- |
| 누가 쓰나 | 스크립트가 `process.env` 로 읽는다 | 사람이 창에 친다 |
| 에이전트가 값을 보나 | **안 본다.** 이름만 쓴다 | (없음) |
| 어디 두나 | 이 폴더의 `.env` | **아무 데도 안 둔다** |
| 다른 컴에 어떻게 가나 | `설치.mjs` 가 옮긴다 | 사람이 브라우저에 한 번 로그인 |

로그인이 필요한 일은 **이미 로그인된 크롬(L3)** 으로 한다. 비밀번호를 저장할 이유가 없다.
자세한 건 `정보/계정.md`.

## .env 쓰는 법

이 폴더에 `.env` 를 만들고 키를 적는다. `설치.mjs` 가 새 컴의 `<프로젝트폴더>/ops/.env` 로 옮긴다.

```
OPENAI_API_KEY=...
VERCEL_TOKEN=...
```

스크립트에서는 이렇게만 쓴다. **값을 코드에 박지 마라.**

```js
const key = process.env.OPENAI_API_KEY;
if (!key) throw new Error("OPENAI_API_KEY 가 없다");
```

## 에이전트가 지킬 것

- `.env` 를 **읽어서 값을 화면에 찍지 마라.** 있는지 없는지만 확인한다.
  ```bash
  node -e "console.log(!!process.env.OPENAI_API_KEY)"
  ```
- 값을 커밋하지 마라. `ops` 저장소는 공개고 커밋 전 검사가 막는다.
- 유료 키를 쓰는 작업은 **예상 비용을 숫자로 먼저 말한다.**
  스크립트에 유료 호출을 넣으면 기본값을 차단으로 두고 사람이 환경변수로 켜게 한다.

## 이 폴더는 구글 드라이브에 있다

드라이브는 사용자 개인 계정이라 남이 못 본다. 다만 **폴더를 남과 공유하면 키까지 같이 간다.**
`에이전트` 폴더는 공유하지 마라. 링크가 필요하면 공개 사이트(https://wnbx.vercel.app)를 쓴다.
