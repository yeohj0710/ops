# CapCut 인물 영상 보정

- **부르는 말**: 영상 보정해줘, 캡컷 보정해줘, 인물 보정해줘, 영상 미용 보정
- **미리 허가**: 지정한 영상의 백업·테스트 사본·보정본을 만든다. 원본과 기존 프로젝트를 보존한다
- **런너**: codex
- **제어층**: L1 준비·대조 → L4 CapCut 보정·내보내기
- **한 번에 걸리는 시간**: 영상 길이와 얼굴 수에 따라 달라짐. 실측 전

## 현재 상태

검증 중인 업무다. 원본 목록·해시·메타데이터 수집과 테스트 사본 백업은 검증했다.
CapCut 보정 영상 내보내기와 완전한 백그라운드 처리는 아직 검증하지 않았다.
준비 명령 성공을 보정 완료로 보고하지 않는다.

## 보정 기준

사용자는 자연스러움보다 예쁘고 잘생기게 보이는 결과를 우선한다.
피부결·잡티·밝기뿐 아니라 얼굴형·눈·턱선도 조절한다. 지나친 변형은 피한다.
얼굴마다, 같은 얼굴도 촬영 거리와 조명마다 값을 따로 맞춘다.
말하기·웃기·고개 돌리기에서도 유지되는지 확인한다.
숫자는 실제 CapCut 항목과 범위를 확인한 뒤 기록한다. 공통값을 지어내지 않는다.

## 실행 순서

1. 사용자 폴더를 <입력>으로 정한다. 기록은 <입력>/etc/capcut-retouch/에 둔다.
2. L1 준비: node "<OPS>/manuals/capcut-retouch/scripts/prepare.mjs" "<입력 절대경로>" "<대표 영상 파일명>"
   대표 파일명은 여러 개 지정할 수 있다. 전체 MOV의 SHA-256(파일 내용 대조값), 길이,
   해상도, 회전 정보, 프레임률, 오디오와 색 정보를 sources.json에 기록한다.
   대표 원본은 하위 구조를 유지해 backup/sources/에 복사하고 해시를 비교한다.
   원본 또는 기존 백업이 달라지면 중단한다. 백업을 덮지 않는다.
   MOV 이외 확장자는 현재 수집 대상이 아니다. 필요하면 수집기를 확장한다.
3. 기존 CapCut 프로젝트를 백업한다. 준비 명령의 자동 백업 대상은 이 PC에서 확인한
   0318, 0403 두 로컬 프로젝트와 프로젝트 목록 파일이다. 다른 프로젝트·저장 위치는
   별도 백업을 먼저 한다. 인증 파일은 복제하지 않는다.
4. L1 또는 별도 환경에서 실제 보정·내보내기가 되는지 확인한다.
   사용자와 입력을 함께 쓰는 L4는 백그라운드가 아니다. 화면 입력이 필요하면
   사용 가능한 시간을 확인한다. 동의 없이 창을 앞으로 가져오지 않는다.
5. CapCut에서 새 테스트 프로젝트를 만들고 원본 대신 검증한 사본을 넣는다.
   기존 프로젝트를 편집하지 않는다. Video → Retouch에서 실제 항목을 확인한다.
   짧은 동일 구간에 강도가 다른 후보를 적용한다. 얼굴별 적용 지원도 확인한다.
6. profiles.json에 파일·구간·대상 얼굴 설명·실제 항목명·값·앱 버전·검수 결과를 기록한다.
   얼굴 설명은 작업 내 구분용이며 신원을 추정하지 않는다. 미검수 프로필을 다른 얼굴에 적용하지 않는다.
7. 검토 영상은 previews/에 내보낸다. 원본과 비교하고 중간 움직임을 무음 검수한다.
   눈·입 흔들림, 턱선 튐, 머리카락·안경 경계, 목과 얼굴의 색 차이,
   주변 선반·글자 휨을 점검한다. 문제가 생긴 항목만 낮춰 다시 확인한다.
8. 통과한 프로필을 해당 촬영분에 적용한다. 인물이 없는 외관·제품 영상은 제외한다.
   최종 영상은 각 촬영 폴더의 보정본/에 저장한다. 기존 출력은 자동 덮어쓰지 않는다.
9. 출력의 화면 방향·표시 해상도·길이·오디오·색을 원본과 대조한다.
   변동 프레임률 평균값을 출력값으로 무작정 쓰지 않는다. 4K 소스를 이유 없이 1080p로
   납품하지 않는다. SDR/HDR 변경도 기록한다.
10. 원본 보존 검사: node "<OPS>/manuals/capcut-retouch/scripts/verify.mjs" "<입력 절대경로>"
    출력 파일·프로필·검수 구간·제외 사유·남은 작업을 기록한다.

## 완료 조건

- 원본 해시가 작업 전과 같다. 사용한 사본의 백업 해시도 같다.
- 지정 범위의 영상마다 보정 결과 또는 제외 사유가 있다.
- 실제 CapCut 보정본의 얼굴 움직임과 출력 메타데이터를 검수했다.
- 프로필과 대상 촬영분을 대응시킬 수 있다.
- 백그라운드 성공은 입력 포커스를 빼앗지 않고 보정·출력·검증했을 때만 기록한다.

## 확인한 제한

- 2026-09-19 Windows CapCut 9.4.0.4015의 배경 캡처가 검게 나왔다.
  접근성 정보는 HomeWindow 한 항목뿐이어서 보정 버튼을 읽을 수 없었다.
- 현재 L4는 입력할 때 대상 창을 활성화한다. 배경 캡처와 배경 입력은 다르다.
- 기존 로컬 프로젝트 두 개에는 재사용할 인물 보정 설정이 없었다.
- 비공식 도구의 미리보기는 CapCut 고유 보정의 최종 출력과 다르다.
  아래 컴파일러는 macOS 9.1을 검증했으며 네이티브 출력 러너는 포함하지 않는다.
- 세로 저장 원본과 회전 정보로 세워지는 원본이 섞여 있다. 폭·높이만 비교하지 않는다.
- 준비 명령은 재실행 시 목록을 재사용한다. 최종 대조에는 verify 명령을 쓴다.
