# 돈

- **무엇에 쓰나**: 돈이 나가는 일을 만났을 때. 유료 API 를 부를 때
- **제어층**: 상관없다. 판단 규칙이다
- **못 하는 것**: 카드번호 직접 입력, 송금과 이체, 주식과 코인 거래

---

## 매뉴얼에 값이 박힌 지출은 묻지 않는다

사람이 업무 이름을 말한 것이 그 절차 전체에 대한 승인이다.
"쇼츠 돌려줘" 안에 조회수 주문 200원이 들어 있으면 그것까지가 시킨 일이다.
한 세션에 한 번씩 다시 묻지 마라. 사람이 원격에 있으면 거기서 일이 멈춘다.

**묻는 대신 알린다.** 지출 직전에 금액과 수량, 대상을 한 줄로 적고 그대로 누른다.

```
조회수 2,000회 x 0.1원 = 200원. 잔액 5,200 → 5,000. 대상은 방금 올린 릴스. 넣는다.
```

**지출 전에 주문내역을 먼저 본다.** 사람이 기다리다 직접 넣어 둔 것을 모르고 또 누르면 두 번 나간다.

## 멈추고 묻는 것

셋 중 하나라도 어긋나면 멈춘다.

- 금액이 매뉴얼과 다를 때
- 잔액이 모자라 충전이 필요할 때
- 대상이 이번 업무에서 만든 것이 아닐 때

**매뉴얼에 없는 지출**은 금액과 항목을 보고하고 승인받아 진행한다.
저장된 결제수단이 있으면 장바구니, 옵션, 쿠폰까지 다 맞춰 놓고 한 마디만 기다린다.

```
결제 준비됐다. 광고 충전 30만원, 등록된 카드. 진행할까?
```

## 절대 안 하는 것

- **카드번호, CVC, 결제 비밀번호를 입력창에 타이핑하지 않는다.**
  등록이 안 된 곳을 만나면 거기서 멈추고 사람에게 알린다. 한 번만 등록해두면 그 뒤로는 계속 된다
- 송금, 계좌이체, 주식이나 코인 거래는 금액과 무관하게 사람이 한다

## 유료 API

`.env` 의 OpenAI 키는 호출마다 현금이 나간다. `LLM_ENABLE=0` 으로 막아뒀다.

- **에이전트가 스스로 풀지 않는다.** 예상 비용을 숫자로 먼저 말하고 사람이 켠다
- 스크립트에 유료 호출을 넣어야 하면 **기본값을 차단**으로 두고 사람이 환경변수로 켜게 한다
- 대량 처리는 에이전트가 직접 한다. 스크립트는 할 일 목록과 검증만 맡는다
- 키를 다른 프로젝트에서 복사해 오지 않는다

키가 있는지만 확인할 때는 값을 찍지 말고 존재만 본다.

```bash
node -e "console.log(!!process.env.OPENAI_API_KEY)"
```

## 비용을 먼저 말하는 형식

작업을 시작하기 전에 한 줄로 적는다. 사람이 보고 판단할 수 있어야 한다.

```
품목 900개를 분류한다. 건당 입력 400토큰, 출력 120토큰.
gpt-5.6-luna 기준 약 0.35달러. 진행할까?
```
