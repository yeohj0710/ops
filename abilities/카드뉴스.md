# 카드뉴스

- **무엇에 쓰나**: 인스타에 올릴 카드뉴스와 이벤트 포스터를 만든다. 나눔, 공지, 정보 카드 전부
- **제어층**: L3 (레퍼런스 찾기, 이미지 뽑기), L1 (Figma MCP 로 조립)
- **못 하는 것**: 없는 제품을 지어내면 안 된다. 실제 제품은 공식 컷을 찾아 쓰고, 생성은 마지막 수단이다

---

## 순서

**맨손으로 디자인하지 마라.** 머리에서 뽑은 레이아웃은 열에 아홉 "AI 티 난다" 로 반려된다.
같은 상황의 실제 인스타 게시물을 먼저 찾고, 그 판을 그대로 쓴다.

1. **레퍼런스를 찾는다** (아래 절)
2. **뼈대를 글로 적는다.** 무엇을 맨 위에 두고 무엇을 크게 할지
3. **이미지를 뽑는다** (아래 절)
4. **피그마에서 한 장씩 짓고 매번 눈으로 본다** (`피그마.md` 의 규칙을 따른다)
5. **PNG 로 뽑아 드라이브 업무 폴더에 둔다**

## 레퍼런스 찾기

크롬으로 인스타 태그 페이지를 연다. 로그인은 이미 돼 있다.

```
https://www.instagram.com/explore/tags/<태그>/
```

상황에 맞는 태그를 고른다. 나눔이면 `팔로워이벤트` `무료나눔` `추첨이벤트`,
정보 카드면 `카드뉴스` `건강정보`, 제품이면 `신제품출시` 식이다.
태그로 안 나오면 구글에 `인스타 <상황> 카드뉴스` 로 검색해서 게시물로 들어가도 된다.

**두 건 이상 본다.** 한 건만 보고 만들면 그 한 장을 베끼게 된다.
두세 건에서 공통으로 나오는 것이 그 판의 문법이고, 그것만 가져온다.

썸네일이 안 뜨면 배경 탭이라 그렇다. **휠을 한 번 굴리면 로드된다.**
게시물을 열었는데 사진이 검게 나오면 잠깐 기다렸다가 다시 캡처한다.

### 나눔, 이벤트 게시물의 공통 문법 (260820 실측)

- 맨 위에 작은 영문 라벨 하나 (`FOLLOWER EVENT`, `BEST SELLER`). 자간을 넓게 준다
- 그 아래 큰 국문 제목 두 줄. 한 어절만 포인트색으로 뺀다
- 제품 사진을 크게. **배경을 지운 것처럼** 깔린다
- `참여 방법` 같은 진한 알약 라벨 + 흰 카드 안에 번호 매긴 세 줄
- 맨 아래 기간과 발표일 한 줄, 그 밑에 계정 핸들
- 배경은 파스텔 크림 한 가지. 얇은 안쪽 테두리 프레임을 두르기도 한다

## 후킹과 강조

- **가장 센 사실을 제목으로 올린다.** 완판, 판매량, 수상, 몇 년 차 같은 것이 여기 해당한다.
  이걸 하단 회색 작은 글씨로 깔면 아무도 안 본다. 260820 에 "현대백화점 팝업마다 완판" 을
  아래 캡션에 뒀다가 "왜 강조를 안 하냐" 고 반려받았다
- **강조는 한 화면에 한 군데.** 어절 하나만 포인트색 + Bold 로 뺀다. 여러 곳을 칠하면 아무 데도 안 보인다
- **숫자는 배지로 뽑는다.** `30명` `2000` 처럼 원형 배지에 넣으면 눈이 먼저 간다
- **제목은 공식적인 명사구로 쓴다.** "안에 든 건 세 가지" 는 구어체라 반려됐고 "주요 성분 3가지" 로 고쳤다.
  카드 제목은 말하듯 쓰지 말고 라벨처럼 쓴다. 본문은 반대로 말하듯 쓴다
- 슬로건과 번역투는 그대로 AI 티가 된다. `copy-tone` 규칙을 따른다

## 컴팩트하게

**슬라이드를 늘리지 마라.** 길면 안 넘긴다.

- 나눔과 이벤트는 **3장이 상한**이다. 1장에 이벤트 정보를 다 넣고 나머지 둘은 붙임이다
- 정보 카드뉴스도 6장을 넘기지 않는다
- 한 장에 한 가지만 말한다. 두 가지를 넣고 싶으면 하나를 버린다
- 260820 에 6장으로 만들었다가 3장으로 줄였다. 줄이고 나서 더 좋아졌다

## 이미지 뽑기

### 순서를 지켜라. 생성은 맨 마지막이다

**실제로 있는 제품, 장소, 사람이면 먼저 찾아본다.** 없는 걸 그려내는 건 마지막 수단이다.
260820 에 올레씨를 그려서 만들었다가 "구글에 치면 공식 제품 이미지가 있는데" 라고 지적받았다.

1. **구글 이미지에서 공식 컷을 찾는다.** `<제품명>`, `<브랜드> <제품명> 상세페이지` 로 친다.
   브랜드 자사몰, 스마트스토어, 쿠팡, 백화점몰 상세페이지에 배경 지운 누끼컷이 거의 다 있다
2. 구도가 안 맞으면 **그 이미지를 ChatGPT 에 올려서 원하는 구도로 가공시킨다.**
   실물 그대로 두고 배경, 각도, 소품, 조명만 바꾸는 거라 제품이 안 틀어진다
3. **아무 데도 없을 때만 처음부터 생성한다.** 이때는 보고에 "생성 이미지" 라고 반드시 적는다

크롬으로 찾은 이미지를 받을 때는 아래 "뽑은 이미지를 피그마로 옮기기" 의 캔버스 방식을 그대로 쓴다.
원본 URL 을 반환값으로 꺼내려 하지 마라. 도구가 막는다.

### 있는 이미지를 ChatGPT 로 가공시키기

새 채팅에 이미지를 올리고 무엇을 유지하고 무엇을 바꿀지 나눠 적는다.

```
올린 사진의 제품은 모양, 색, 라벨, 비율을 그대로 유지해줘. 라벨 글자도 바꾸지 마.
배경만 아주 연한 크림색 단색으로 바꾸고, 병 옆 바닥에 레몬 반쪽과 올리브 몇 알을 놓아줘.
정사각형, 정면 각도, 부드러운 자연광, 그림자는 아래로 은은하게만.
```

**"그대로 유지" 를 안 적으면 제품을 새로 그려 버린다.** 라벨 글자도 같이 못 박아야 한다.
가공본을 받으면 원본과 나란히 놓고 라벨과 병 모양이 같은지 눈으로 본다. 틀어졌으면 다시 시킨다.

파일 올리기는 `file_upload` 가 로컬 경로를 거부할 때가 있다. 그때는 `browser-file-upload-workaround`
(postMessage) 를 쓴다.

### 처음부터 생성해야 할 때

**크롬에 로그인된 ChatGPT 로 뽑는다.** 사람이 쓰는 유료 계정이라 따로 돈이 안 나간다.

새 탭을 만들어 `chatgpt.com` 을 열고 **새 채팅**을 누른다.
사람이 쓰던 대화에 이어서 쓰면 그 대화가 오염된다.

프롬프트에 넣을 것.

- **각각 개별 이미지로 몇 장** 이라고 못 박는다. 안 그러면 콜라주 한 장으로 합쳐 준다
- 비율(4:5 세로, 정사각형)
- **배경색을 지정한다.** "아주 연한 크림색 단색 하나만" 처럼. 나중에 슬라이드 배경과 맞추기 쉽다
- **글자와 라벨 문구는 절대 넣지 마.** 안 적으면 엉터리 글자를 그려 넣는다
- **물방울과 기포는 넣지 마.** 사람이 싫어하는 질감이다
- "광택 3D 렌더링이나 클립아트 말고 실사 사진 느낌으로"

### 프롬프트 입력은 스크립트로 넣는다

**긴 한국어를 `computer` 의 `type` 으로 치면 글자가 깨지고 공백이 사라진다.** 260820 실측이다.
입력창이 ProseMirror 라 값 대입도 안 먹는다. `execCommand` 로 넣는다.

```js
const ed = document.querySelector('#prompt-textarea') || document.querySelector('[contenteditable="true"]');
ed.focus();
document.execCommand('selectAll', false, null);
document.execCommand('delete', false, null);
document.execCommand('insertText', false, "여기에 프롬프트 전문");
ed.textContent.length   // 길이가 맞는지 확인하고 Enter
```

### 뽑은 이미지를 피그마로 옮기기

세 갈래를 다 막혀 보고 남은 길이 이거다. **아래 순서 그대로 하면 된다.**

1. `upload_assets` 로 필요한 수만큼 업로드 주소를 받는다 (10분 만료, 한 번만 쓴다)
2. 페이지 안에서 이미지를 캔버스에 그려 blob 으로 만들고 다운로드 폴더에 떨군다

   ```js
   const imgs=[...document.querySelectorAll('img')].filter(i=>/oaiusercontent|backend-api\/(files|estuary)/.test(i.src));
   const seen=new Set(), uniq=[];
   for(const i of imgs){ if(!seen.has(i.src)){ seen.add(i.src); uniq.push(i); } }   // 전체 src 로 걸러야 한다
   for(let i=0;i<uniq.length;i++){
     const im=new Image(); im.crossOrigin='anonymous';
     await new Promise((ok,no)=>{im.onload=ok; im.onerror=no; im.src=uniq[i].src;});
     const c=document.createElement('canvas'); c.width=im.naturalWidth; c.height=im.naturalHeight;
     c.getContext('2d').drawImage(im,0,0);
     const b=await new Promise(r=>c.toBlob(r,'image/png'));
     const a=document.createElement('a'); a.href=URL.createObjectURL(b); a.download=`shot-0${i+1}.png`;
     document.body.appendChild(a); a.click(); a.remove();
     await new Promise(r=>setTimeout(r,700));
   }
   ```

3. 다운로드 폴더에서 curl 로 올린다. 응답에 `imageHash` 가 온다

   ```bash
   curl -s -X POST "<submitUrl>" -F "file=@shot-01.png;type=image/png"
   ```

4. 그 해시를 `{type:'IMAGE', imageHash, scaleMode:'FILL'}` 로 노드 fill 에 넣는다
5. 업로드가 캔버스에 만들어 놓은 원본 프레임은 `x=-1500` 쯤으로 밀어 두고 이름 앞에 `소스` 를 붙인다
6. **작업이 끝나면 다운로드 폴더의 임시 PNG 를 지운다**

### 사진이 네모 상자로 보일 때

생성 이미지 배경과 슬라이드 배경이 다르면 사진이 상자로 뜬다. 오려붙인 것처럼 보이게 하려면 이렇게 한다.

```bash
python -c "
from PIL import Image
im=Image.open('shot-01.png').convert('RGB'); w,h=im.size
for p in [(5,5),(w-6,5),(5,h-6),(w-6,h-6)]: print(p,'#%02X%02X%02X'%im.getpixel(p))"
```

- 나온 값을 **슬라이드 배경색으로 그대로 쓴다.** 그리고 사진의 `cornerRadius` 를 0 으로 둔다
- 사진이 여러 장이라 배경 톤이 서로 다르면, 한 장을 기준으로 잡고 나머지는
  `ImagePaint` 의 `filters` 로 맞춘다. `{exposure:0.07, contrast:-0.03, temperature:0.05}` 정도면 붙는다

**공식 컷을 쓸 때는 반대로 간다. 팔레트를 사진에 맞추지 말고 사진을 팔레트에 맞춘다.**
260820 에 공식 컷 배경(`#EEEAE3`)에 맞춰 슬라이드를 회색으로 바꿨다가 "아까 색이 나았다" 로 되돌렸다.
쓰던 배경색이 더 예쁘면 그걸 지키고, **사진 쪽을 PIL 로 물들여서** 올린다.

```python
from PIL import Image
im = Image.open(src).convert("RGB")
r, g, b = im.split()
r = r.point(lambda v: min(255, int(v * 249 / 238 + 0.5)))   # 238 -> 249 (원본R -> 목표R)
g = g.point(lambda v: min(255, int(v * 239 / 234 + 0.5)))
Image.merge("RGB", (r, g, b)).save(dst)
```

채널마다 `목표값 / 원본값` 을 곱하면 된다. 제품 색도 같이 몇 퍼센트 움직이지만 눈에 안 띈다.
바꾼 파일을 새로 업로드하고 해시를 갈아끼운다. **원본도 같이 남겨 둔다.**

**한글이 든 경로를 `python -c` 로 넘기면 깨진다.** 스크립트 파일로 써서 실행한다.

### 제품이 사진 안에서 작을 때

공식 상세컷은 여백이 넓어서 그대로 넣으면 제품이 작게 나온다. `scaleMode` 를 `CROP` 으로 바꾸고
`imageTransform` 으로 제품만 파고든다. 행렬은 `[[가로비율,0,가로시작],[0,세로비율,세로시작]]` 이고
값은 0에서 1 사이 비율이다.

```js
ph.fills=[{type:'IMAGE', imageHash:HASH, scaleMode:'CROP',
  imageTransform:[[0.690,0,0.163],[0,0.811,0.127]]}];   // 가로 69%, 세로 81% 만 보여준다
```

**사진 틀의 가로세로 비를 잘라낼 영역에 맞춰라.** 세로로 긴 제품이면 틀도 세로로 길게(400x470 식) 잡는다.
정사각 틀에 세로 제품을 넣으면 좌우 여백만 늘어난다.

## 알려진 함정

- **`figma.createAutoLayout()` 은 흰 fill 이 기본이다.** `fills=[]` 를 안 하면 글자 줄마다 흰 띠가 깔린다.
  260820 에 첫 슬라이드가 통째로 이것 때문에 망가졌다
- **크롬에서 이미지 URL 을 반환값으로 받으려 하면 도구가 막는다.** 쿼리스트링이 자격증명처럼 보여서다.
  URL 을 밖으로 꺼내지 말고 **페이지 안에서 처리를 끝낸다**
- **`chatgpt.com` 에서 `mcp.figma.com` 으로 POST 하면 CORS 로 죽는다.** 이미지 `fetch` 자체는 200 으로 된다.
  그래서 위 절차가 캔버스와 다운로드를 거친다. 페이지에서 바로 올리려는 시도는 다시 하지 마라
- **피그마 `query()` 셀렉터에 한글을 넣으면 파서가 죽는다.** `Invalid selector: unexpected character` 가 뜬다.
  `findOne(n => n.type==='TEXT' && n.characters.indexOf('완판')!==-1)` 로 잡는다
- **`setRangeFills` 인덱스는 줄바꿈과 공백을 다 센다.** 손으로 세면 한 칸씩 어긋난다.
  `const i = node.characters.indexOf('완판')` 로 잡고 `i, i+2` 를 쓴다
- **텍스트를 감싼 알약 프레임은 `primaryAxisAlignItems='CENTER'`** 를 줘야 글자가 가운데로 온다.
  안 주면 폭을 채운 뒤 왼쪽에 붙는다
- **인스타 태그 페이지는 배경 탭에서 이미지를 안 그린다.** 휠을 한 번 굴린다
- **오른쪽 끝 글자가 잘리면** 컨테이너가 `FILL` 인지, 부모 패딩이 88 인지 본다
- 큰따옴표 여는 기호(`“`)는 Pretendard 에서 기울어진 겹따옴표로 그려진다. 인용 부호로 쓰면 그 모양이다

## 작업 끝에

- PNG 는 `<드라이브>/영상 편집/.<대상>/_<건 이름>/` 처럼 그 건 폴더에 모은다
- 피그마 파일 링크를 보고에 같이 적는다. 파일 이름은 만들 때만 정할 수 있다
- **생성 이미지를 쓴 자리는 보고에 명시한다.** 공식 컷을 못 찾은 자리라는 뜻이다
- 날짜, 마감처럼 못 받은 값은 `○월 ○일` 로 두고 무엇이 비었는지 보고한다
