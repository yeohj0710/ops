# 피그마

- **무엇에 쓰나**: 제안서, 발표자료, 소개서, IR 덱을 만든다. 있는 덱을 고친다
- **제어층**: L1 (Figma MCP 가 플러그인 API 로 직접 그린다. 브라우저 클릭 아님)
- **못 하는 것**: 파일 이름은 만들 때만 정할 수 있다. 나중에 못 바꾼다

인스타에 올릴 **카드뉴스와 이벤트 포스터는 `카드뉴스.md` 를 본다.** 여기는 1920x1080 덱 얘기다.

**원본이 이미 PPT 로 있으면 다시 그리지 마라.** 아래 "PPT 를 그대로 옮기기" 로 간다.

---

## 순서

**맨손으로 새로 그리지 마라.** 회사에는 이미 완성된 덱이 여러 벌 있고,
새 자료는 그중 하나의 디자인 체계를 그대로 떠서 쓴다. 그게 제일 빠르고 결과도 제일 좋다.

1. **어느 덱을 본뜰지 정한다** (아래 표)
2. **그 파일에서 토큰을 실측한다.** 기억으로 색과 크기를 지어내지 마라
3. **새 파일을 만든다**
4. **슬라이드를 한두 장씩 짓고 매번 눈으로 본다**
5. **PDF 로 뽑는다**

## 본뜰 덱

| 쓸 자리 | 파일 | 결 |
| --- | --- | --- |
| 회사 소개, IR, 투자자와 대기업에 내는 것 | `35J7WaToONP9rKSXyzOe1p` (IR 덱) | 파란 그라데이션, 흰 카드, 강조 #1e62a8 |
| 서비스 제안서, 협업 제안, 소개서 | `YFZ8PcMMTuYSUJkjC21fn4` (병의원 마케팅) | 따뜻한 베이지 #f5f1ea, 다크 필 #2b2723, 강조 레드 #c0392b |

둘 다 1920x1080 이고 폰트는 Pretendard 다. 영문 라벨만 Inter 를 쓴다.
**한글에 Inter 를 넣으면 글자가 사라진다.** 섞지 마라.

## 토큰 뜨는 법

`use_figma` 로 읽기 스크립트를 돌려 실제 값을 받아온다. 대표 슬라이드 두세 장이면 충분하다.

```js
// 프레임 목록
const fr = figma.currentPage.children.filter(n => n.type === 'FRAME');
fr.sort((a,b) => (a.y-b.y) || (a.x-b.x));
return fr.map(f => ({ id:f.id, name:f.name, w:Math.round(f.width), h:Math.round(f.height) }));
```

그다음 한 프레임의 자식을 좌표, 색, 폰트, 크기, 자간, 행간까지 통째로 덤프해서 그대로 베낀다.
프레임 자체의 `fills` 도 같이 뜬다. 배경 그라데이션이 거기 있다.

## 만들고 그리기

**스킬 두 개가 필수다. 안 부르면 조용히 깨진다.**

- `create_new_file` 을 부르기 전에 **`figma-create-new-file` 스킬**
- `use_figma` 를 부르기 전에 **`figma-use` 스킬**

새 파일은 `whoami` 로 planKey 를 받아서 만든다. **이름은 이때만 정할 수 있다.**

슬라이드는 프레임을 격자로 깐다. 가로 2120 간격, 세로 1380 간격이면 겹치지 않는다.
한 번에 한두 장씩 짓고 `await frame.screenshot({scale:0.5})` 로 **매번 눈으로 확인한다.**
열 장을 한 번에 짓고 나중에 보면 다 뜯어고치게 된다.

## 그림 자료

**픽토그램은 직접 그리지 마라.** 손으로 그린 티가 나서 오히려 반감을 산다.
Lucide 아이콘을 받아 색만 바꿔 올린다.

```bash
curl -sL -o factory.svg "https://unpkg.com/lucide-static@latest/icons/factory.svg"
# currentColor 를 실제 색으로 바꾸고 width/height 를 키운다
```

`upload_assets` 로 올리면 **편집 가능한 벡터**로 들어온다. 올릴 때 파일 이름이 레이어 이름이 되니
`icon-factory.svg` 처럼 이름을 붙여 올리면 나중에 찾기 쉽다.
슬라이드에 넣을 때는 원본을 `clone()` 해서 쓰고, 원본은 캔버스 밖(x = -900 쯤)에 세워둔다.

사진은 무료 라이선스에서 받는다. 표지와 클로징에만 쓰고 본문은 도식으로 채우는 게 낫다.
스톡 사진을 장마다 깔면 오히려 싸 보인다.

## 생성 이미지와 바깥 이미지 넣기

덱에 쓸 그림이 회사 자료에 없으면 **크롬에 로그인된 ChatGPT 로 뽑는다.** 사람 유료 계정이라 돈이 안 나간다.
프롬프트 요령과 옮기는 절차는 `카드뉴스.md` 의 "처음부터 생성해야 할 때", "뽑은 이미지를 피그마로 옮기기" 를
그대로 쓴다. 여기서 다시 적지 않는다.

**옮기는 길은 하나뿐이다. 페이지 안에서 캔버스에 그린 뒤 `a.download` 로 다운로드 폴더에 떨군다.**
페이지가 스스로 시작하는 다운로드라 아래 차단에 안 걸린다. 받은 PNG 는 `<사용자폴더>/Downloads` 에 떨어지고,
거기서 curl 로 `upload_assets` 주소에 올린다.

260821 에 아래를 전부 다시 막혀 봤다. **시간 버리지 말고 건너뛰어라.**

- 페이지에서 `mcp.figma.com` 으로 `fetch`, `XHR` POST: CORS 로 죽는다
- 크롬에 uBlock Origin 이 붙어 있어 페이지 `fetch` 를 프록시한다. 바깥 주소는 거의 다 막힌다
- 로컬 수신 서버(127.0.0.1)로 POST: chatgpt.com CSP 가 막는다
- 숨긴 `form` 을 만들어 submit: CSP form-action 이 막는다
- 라이트박스 다운로드 아이콘, 메시지 `...` 메뉴: 확장 샌드박스라 파일이 안 떨어진다
- 이미지 주소를 curl 로 직접: 서명이 붙어 있어도 세션 쿠키가 없으면 `File stream access denied`

**아이콘은 업로드까지 갈 것도 없다.** Lucide svg 를 curl 로 받아 안쪽 `<path>` 만 꺼낸 뒤
`figma.createNodeFromSvg` 에 넣으면 편집 가능한 벡터로 바로 들어온다. stroke 는 덱 강조색, 굵기 1.8 로 둔다.

```bash
curl -sL -o target.svg "https://unpkg.com/lucide-static@latest/icons/target.svg"
```

**옛 덱 이미지를 다시 쓸 때는 같은 파일 안으로 먼저 옮겨 놓는다.** `imageHash` 는 파일 단위라
같은 파일이면 재업로드 없이 `fills` 에 해시를 그대로 꽂으면 된다. 다른 파일이면 안 된다.
옛 프레임을 그 파일 Backup 페이지에 붙여넣고 해시만 뽑아 쓰는 게 제일 빠르다.
**원본 가로세로 비를 지켜야 크롭이 안 바뀐다.**

## 도식

화살표는 **글자 `→` 를 띄워놓지 말고 진짜 벡터로 그린다.** 선 하나와 삼각형 하나면 된다.
좌표는 절대값으로 계산해 놓고, 경로 데이터는 bbox 기준으로 옮긴 뒤 노드 x, y 를 bbox 원점에 둔다.
그래야 어긋나지 않는다.

## PDF 로 뽑기

Figma MCP 에는 PDF 내보내기가 없다. 프레임을 하나씩 받아서 묶는다.

```
get_screenshot {fileKey, nodeId, maxDimension: 1920}   # 프레임마다 한 번
```

돌아온 URL 을 curl 로 받고 PIL 로 묶는다.

```bash
python -c "
from PIL import Image; import glob
fs=sorted(glob.glob('s*.png')); ims=[Image.open(f).convert('RGB') for f in fs]
ims[0].save('deck.pdf', save_all=True, append_images=ims[1:], resolution=150.0)"
```

프레임 이름을 `01-표지` 처럼 번호로 시작하게 지어두면 정렬이 그대로 순서가 된다.

## 글 쓰는 규칙

산출물 문체는 회사 규칙을 그대로 따른다. 특히 이 셋을 어기면 다시 만들게 된다.

- **제목은 명사구.** "첫 콘텐츠를 올립니다" 가 아니라 "첫 콘텐츠 업로드까지"
- **제목에 관형절을 못 붙인다. 명사+명사로만 간다.** "~하는 ○○", "~되는 ○○", "~가능한 ○○" 은 한국에서 제목으로 안 쓰는 말투다.
  "이 제안이 나온 자리" 가 아니라 "제안 배경", "두 회사가 함께 들어가는 이유" 가 아니라 "공동 수행 이유",
  "재사용 가능한 콘텐츠" 가 아니라 "콘텐츠 자산". 슬라이드 제목만이 아니라 카드 제목과 띠 제목도 같다
- **가운뎃점과 줄표를 쓰지 않는다.** 쉼표나 괄호로 바꾼다. 만들고 나서 한 번 전수 검사해라
- **회색 작은 글씨 금지.** 본문은 17px 이상, 충분히 진한 색으로

## PPT 를 그대로 옮기기

이미 만들어 둔 PPTX 를 Figma 에서 고칠 수 있게 옮기는 일이 자주 온다. 두 덱을 합쳐
한 벌로 만들라는 것도 같은 일이다. **눈으로 보고 다시 그리면 하루가 가고 결과도 안 맞는다.**
PPTX 는 그냥 zip 이고 안에 좌표, 폰트, 색, 크롭이 전부 숫자로 들어 있다. 그걸 읽어서 옮긴다.

변환기가 저장소에 있다. `<OPS>/tools/pptx2figma/pptx2figma.py`. 세 번에 나눠 돈다.

```bash
python "<OPS>/tools/pptx2figma/pptx2figma.py" prep  "<덱.pptx>" --out work/deck
#   -> spec.json 과 assets/ 가 생기고, 필요한 업로드 URL 개수를 알려준다
#   -> upload_assets 를 그 개수로 한 번 부르고, 응답 uuid 를 work/deck/urls.txt 에 붙여넣는다
python "<OPS>/tools/pptx2figma/pptx2figma.py" upload "<덱.pptx>" --out work/deck
python "<OPS>/tools/pptx2figma/pptx2figma.py" build  "<덱.pptx>" --out work/deck
#   -> work/deck/build/batchNN.js. 파일 내용을 use_figma 의 code 에 그대로 넣는다
```

슬라이드를 골라 뽑으려면 `--slides 1,2,5-8`. **두 덱을 합칠 때는 덱마다 따로 돌리고**
뒤 덱에 `--start` 로 격자 번호를 이어 주면 프레임이 안 겹친다.

옮긴 뒤에는 **원본 PDF 와 나란히 놓고 눈으로 대조한다.** PPTX 옆에 PDF 가 없으면
파워포인트로 뽑아 두고, 있으면 PyMuPDF 로 페이지를 이미지로 뽑아 비교한다.

```bash
python -c "import fitz; d=fitz.open('원본.pdf'); [d[i].get_pixmap(dpi=96).save('ref/%02d.png'%(i+1)) for i in range(d.page_count)]"
```

### 변환기가 대신 처리해 주는 것들

직접 짤 일이 생기면 이 여섯 개를 반드시 넣어야 한다. 하나라도 빠지면 결과가 티 나게 어긋난다.

- **굵기는 `b` 속성이 아니라 폰트 이름에 있다.** 이 회사 덱은 런마다
  `<a:latin typeface="Pretendard Bold">` 로 굵기를 준다. `b="1"` 만 보면 **부분 강조가 전부 사라진다**
- **pt 를 px 로 바꿀 때 4/3 을 곱한다.** 좌표는 EMU 를 9525 로 나눈다(96dpi).
  `<a:normAutofit fontScale>` 이 있으면 글자 크기에 그것도 곱한다
- **`bodyPr wrap="none"` 은 줄바꿈 금지다.** Figma 에서 `WIDTH_AND_HEIGHT`,
  `square` 면 `HEIGHT` 에 폭 고정. 안 나누면 제목이 멋대로 접힌다
- **`<a:srcRect>` 는 잘라 쓴 그림이다.** Figma `scaleMode:'CROP'` 과
  `imageTransform:[[w,0,l],[0,h,t]]` 로 옮긴다. 덱 하나에 크롭이 3할쯤 된다. 무시하면 다 어긋난다
- **그룹(`grpSp`)은 좌표가 별도 공간이다.** `ext/chExt` 로 배율, `off - chOff*배율` 로
  이동을 구해 평탄하게 편다. 안 하면 그룹 안 요소가 화면 밖으로 날아간다
- **표는 Figma 에 노드가 없다.** 셀마다 사각형(헤더 #F1F2F1, 본문 흰색, 테두리 1px #9A9A99)과
  텍스트를 따로 깐다

### 이미지

원본 PPTX 는 100MB 를 넘기도 한다. **표시 크기의 2배로 줄여서 올린다.** 100장이 6MB 면 충분하다.
`upload_assets` 는 count 만큼 업로드 URL 을 한 번에 주고 그 URL 로는 직접 POST 하니
**MCP 호출은 1회로 끝난다.** 장당 10MB 를 넘으면 막힌다.

## 알려진 함정

- 파일 이름은 `create_new_file` 때만 정해진다. 플러그인 API 로 못 바꾼다. 바꾸려면 사람이 UI 에서 한다
- `layoutSizing` 은 부모가 오토레이아웃일 때만 `HUG` 와 `FILL` 이 먹는다. `appendChild` 부터 하고 설정한다
- 색은 0에서 1 범위다. 255 로 넣으면 튕긴다
- 텍스트를 만지기 전에 **그 노드가 쓰는 폰트를 먼저 로드**한다. 안 하면 "unloaded font" 로 죽는다
- 어떤 파일은 본문에 특수 제어문자가 섞여 `get_metadata` 가 아예 안 된다. 그럴 땐 `use_figma` 읽기 스크립트로 구조를 본다
- **`resize()` 가 `textAutoResize` 를 `NONE` 으로 되돌린다.** `textAutoResize='HEIGHT'` 를 먼저 주고
  `resize(폭, 10)` 으로 폭을 잡으면 높이가 10px 에 고정된다. 글자는 상자 밖으로 흘러나오고,
  가운데 정렬한 것은 10px 기준으로 중심을 잡아 아래로 밀린다. 화면에는 그럴듯해 보여서 늦게 발견한다.
  **폭을 먼저 주고 그다음에 `textAutoResize` 를 건다**
- **줄간격을 픽셀로 박지 마라.** PPT 박스 높이에서 역산하면 Pretendard 실제 줄 높이보다
  최대 16% 짧아져 상자가 글자보다 작아진다. `lineHeight` 는 `AUTO` 로 두고 **위치만 원본 좌표로 앉힌다.**
  세로 정렬은 원본 `bodyPr` 의 anchor(t/ctr/b)와 PPT 박스 높이로 계산한다
- 만들고 나서 **텍스트 전수 검사**를 한 번 돌린다. `textAutoResize === 'NONE'` 인 것,
  상자가 글자보다 짧은 것, 프레임 밖으로 나간 것 세 가지를 세면 위 함정에 빠졌는지 바로 안다
