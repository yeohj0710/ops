# 구글 드라이브

- **무엇에 쓰나**: 회사 서류, 로고, 이미지, 예전 산출물을 찾는다. 만든 것을 사람이 폰에서 볼 수 있게 둔다
- **제어층**: L1 (드라이브가 이 컴에 `G:` 로 마운트돼 있다. 그냥 파일이다)
- **못 하는 것**: 남에게 공유 링크를 여는 것은 사람 확인을 받는다

---

## 그냥 파일로 다룬다

드라이브 앱이 `G:/내 드라이브/` 로 마운트돼 있다. API 를 부를 일이 없다.
`ls`, `cat`, `cp`, `find` 가 다 통하고, `Read` `Write` `Glob` 도 그대로 쓴다.

```bash
ls "G:/내 드라이브/여형준님/"
find "G:/내 드라이브/여형준님/00 핵심 자료" -iname "*로고*"
```

**경로에 공백과 한글이 많다.** 반드시 따옴표로 감싼다.

## 어디에 무엇이 있나

| 찾는 것 | 어디 |
| --- | --- |
| 이 시스템의 뿌리 | `G:/내 드라이브/에이전트/시작.md` |
| 사업자등록증, 인감, 도장, 로고, 명함, 사업계획서 | `G:/내 드라이브/여형준님/00 핵심 자료/` |
| 지원사업과 공모전 서류 | `여형준님/03 지원사업 공모전/` |
| TIPS 관련 | `여형준님/10 TIPS/` |
| 한 번짜리 업무 산출물 | `여형준님/19 단건 업무/<업무 이름>/` |
| 제약사 협업 자료 | `내 드라이브/[협업] 제약회사 제품 마케팅 협업/` |
| 제품별 폴더 | `내 드라이브/[제품] ...`, `[약국] ...`, `[어플] ...` |

무엇이 어느 파일인지 헷갈리면 드라이브 `정보/핵심자료.md` 를 먼저 연다.
**서류 원본의 사본을 만들지 마라.** 경로를 알려주면 된다.

## 만든 것을 어디에 두나

한 번짜리 업무면 `여형준님/19 단건 업무/<업무 이름>/` 에 폴더를 만들고 거기 둔다.
산출물만 두지 말고 **배경 메모를 같이 남긴다.** 다음에 열었을 때 왜 이렇게 했는지 알아야 한다.

메모에 넣을 것: 무엇을 왜 만들었나, 어떤 숫자를 어디서 가져왔나,
사람이 정해야 할 것, 원본 파일(피그마 링크 등) 주소.

## 사람 폰으로 넘기는 법

**이게 파일을 사람에게 보내는 기본 경로다.** 카톡으로는 못 보낸다(`카톡.md`).

드라이브에 두고 경로를 알리면 사람이 폰 드라이브 앱에서 바로 연다.
거기서 공유를 눌러 카톡이든 메일이든 사람이 직접 보낸다.
파일이 동기화되는 데 몇 초 걸리니 알리기 전에 파일이 실제로 놓였는지 확인한다.

## 알려진 함정

- **동기화가 즉시가 아니다.** 방금 쓴 파일을 폰에서 못 찾는다고 하면 잠깐 기다리라고 한다
- 드라이브 폴더 안에 git 저장소를 두지 마라. 동기화가 `.git` 을 건드려 깨뜨린다
- `desktop.ini` 가 폴더마다 있다. 목록을 셀 때 빼고 센다
- 같은 서류가 여러 폴더에 있으면 `제출용 서류/` 것이 최신이다

## 하지 않는 것

- 주민등록번호와 공동인증서(NPKI) 폴더는 열지도 옮기지도 않는다
- 인감증명서와 통장사본을 바깥으로 보내기 전에 사람에게 확인받는다
- 공유 링크를 만들어 남에게 여는 것은 사람이 정한다
