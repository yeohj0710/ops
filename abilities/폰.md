# 폰 (안드로이드)

- **무엇에 쓰나**: PC 크롬으로 못 보는 앱을 본다. 샤오홍슈처럼 웹이 막힌 곳이 그렇다
- **제어층**: L1 (adb 명령). 화면 좌표를 찍는 게 아니라 **화면을 글자로 읽는다**
- **못 하는 것**: 한글과 중국어 타이핑. 아래 "글자를 못 친다" 를 보라

---

## 붙었는지부터 본다

```bash
adb devices -l
```

`device` 로 나오면 붙은 것이다. `unauthorized` 면 폰 화면에 뜬 허용 창을 사람이 눌러야 한다.
`adb` 는 `%LOCALAPPDATA%\Microsoft\WinGet\Packages\Google.PlatformTools_*\platform-tools\adb.exe` 에 있다.

## Git Bash 는 폰 경로를 망가뜨린다

`/sdcard/ui.xml` 을 그대로 쓰면 MSYS 가 `C:/Program Files/Git/sdcard/ui.xml` 로 바꿔 버린다.
파일이 엉뚱한 데로 가고 `failed to stat remote object` 가 뜬다.

```bash
export MSYS_NO_PATHCONV=1     # 한 번 켜 두면 그 세션 내내 안 바뀐다
```

## 화면을 글자로 읽는다

**스크린샷을 찍어 눈으로 보지 마라.** 느리고 틀린다. 화면 트리를 통째로 받아 글자만 뽑는다.

```bash
adb shell 'uiautomator dump /sdcard/ui.xml >/dev/null 2>&1; cat /sdcard/ui.xml' > ui.xml
```

`text="..."` 와 `content-desc="..."` 두 가지를 다 뽑아야 한다.
**숫자와 뜻은 대개 `content-desc` 에 있다.** 샤오홍슈 프로필에서 노트별 좋아요가 거기 있다.

```
text        里森 / rednote 아이디: 953443978 / IP：United Kingdom / 484.2K / 팬
content-desc 视频,...,来自里森,146861赞，
```

지금 어느 앱 어느 화면인지는 이걸로 본다.

```bash
adb shell "dumpsys activity activities | grep -m2 topResumedActivity"
```

## 글자를 못 친다

**`adb shell input text` 는 ASCII 만 된다.** 한글이나 중국어를 넣으면
`java.lang.NullPointerException: Attempt to get length of null` 이 나고 아무것도 안 쳐진다.
260827 에 샤오홍슈 조사가 여기서 막혀 11일을 헛돌았다.

**타이핑을 피해라. 딥링크로 바로 간다.** 대부분의 앱이 스킴을 연다.

```bash
adb shell am start -a android.intent.action.VIEW -d "xhsdiscover://user/<24자리 user_id>"
```

검색어를 꼭 쳐야 하면 사람에게 한 번 쳐 달라고 부탁하는 게 빠르다.
ADBKeyBoard 같은 입력기를 깔지 마라. 폰에 앱을 설치하는 건 사람이 정한다.

## 샤오홍슈에서 쓰는 딥링크

| 무엇 | 주소 |
| --- | --- |
| 프로필 | `xhsdiscover://user/<24자리 user_id>` |
| 노트 | `xhsdiscover://item/<노트 id>` |

**24자리 user_id 가 열쇠다.** 공개 웹의 프로필 주소(`xiaohongshu.com/user/profile/<24자리>`)에서 얻는다.
닉네임만 있고 id 가 없으면 딥링크를 못 쓴다. 그런 후보는 공개 웹에서 id 를 먼저 찾는다.

프로필 한 화면에서 이만큼 나온다. 스크롤도 검색도 필요 없다.

닉네임, rednote 표시 아이디, **IP 위치**, 팔로우 수, 팬 수, 받은 좋아요 합계, bio,
지역과 카테고리 태그, 최근 노트별 좋아요 수.

**IP 위치가 한국 상주 판정의 첫 관문이다.** `IP：United Kingdom` 이면 한국 후보가 아니다.

## 하지 않는 것

- **읽기만 한다.** 팔로우, 좋아요, 저장, 댓글, 쪽지, 게시, 설정 변경을 하지 마라
- **앱을 설치하거나 지우지 마라.** 사람 폰이다
- **잠금 화면을 풀지 마라.** 꺼져 있으면 켜 달라고 부탁한다
- 캡차나 로그인 요구가 뜨면 **우회하지 말고** 시각을 적고 그 표면을 쉰다

## 알려진 함정

- **`input text` 는 비ASCII 를 못 친다.** 위를 보라. 딥링크로 우회한다
- **Git Bash 가 `/sdcard/` 를 윈도 경로로 바꾼다.** `MSYS_NO_PATHCONV=1` 을 켠다
- **`uiautomator dump` 뒤에 바로 `adb pull` 하지 말고 `cat` 으로 받아라.** pull 은 경로 변환에 또 걸린다
- **화면이 아직 안 그려졌는데 dump 하면 빈 트리가 온다.** 딥링크를 열고 3~4초 기다린다
- **한 화면을 두 번 dump 하면 값이 조금 다를 수 있다.** 노트 좋아요는 계속 오른다. 기준 시각을 적는다
- **폰은 하나뿐이다.** 세션 여러 개가 동시에 만지면 서로 화면을 갈아친다.
  `<OPS>/scripts/browser-claim.mjs` 와 같은 이유로, 폰을 쓸 때도 누가 쓰는지 적고 시작한다
