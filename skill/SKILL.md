# 회사 업무 관제탑

업무 하나가 `<OPS>/manuals/<업무id>/MANUAL.md` 에 절차서로 적혀 있다.
사람은 배경 설명 없이 한 문장만 말한다. 이 스킬이 그 한 문장을 처리한다.

`<OPS>` 는 이 스킬을 설치한 관제탑 폴더다. 보통 `C:/dev/ops` 이고,
정확한 경로는 아래 명령을 한 번 돌리면 첫 줄에 나온다.

---

## 트리거 1. 업무 실행

사람이 등록된 업무 이름을 말했다. ("카톡 봐줘", "제안서 만들어줘")

```bash
node "C:/dev/ops/ops.mjs" manuals "○○"
```

**나오면** 그 `MANUAL.md` 를 **끝까지** 읽고 그대로 한다. 요약해 읽지 마라.
배경을 되묻지 마라. 매뉴얼이 배경이다.
시작 전에 두 개를 더 읽는다.

- `C:/dev/ops/AGENTS.md`: 상시 지침(제어층 사다리, 겹침 방지, 공개 규칙)
- `C:/dev/ops/runners/claude.md` 또는 `runners/codex.md`: 네가 어떤 도구로 화면을 만지는지

**안 나오면** 매뉴얼이 없는 업무다. `C:/dev/ops/manuals/_new-manual/MANUAL.md` 를 펴고
**기록 모드**로 진행한다. 하면서 적은 기록이 그대로 매뉴얼 초안이 된다.

**끝냈으면 매뉴얼을 고치고 끝낸다.** 이번에 헤맨 것, 매뉴얼이 틀렸던 것, 새로 뚫은 길을
제자리에 옮긴다. 어디에 적는지는 `AGENTS.md` 의 "막혔다 뚫었으면 반드시 적고 끝낸다" 에 있다.
고쳤으면 **커밋하고 push 한다.** 안 적으면 다음 세션이 같은 벽에 그대로 부딪힌다.

## 트리거 2. 새 업무 등록

사람이 "○○ 업무로 등록해줘", "매뉴얼로 만들어", "시스템에 반영해",
"다음에도 이렇게 해줘", "방금 한 거 등록해" 라고 했다.

```bash
node "C:/dev/ops/ops.mjs" new <영문-id> --title "○○"
```

뼈대가 생긴다. 방금 한 일이 있으면 그걸 그대로 옮기고, 없으면 절차를 물어 채운다.

채울 때 지키는 것 세 개.

1. **도구 이름 대신 제어층으로 적는다.** "claude-in-chrome 으로" 가 아니라 "L3 으로".
   도구는 `runners/*.md` 에만 둔다. 그래야 도구가 바뀌어도 매뉴얼을 안 고친다.
2. **절대경로 대신 `<OPS>` `<DEV>` 로 적는다.** 다른 컴에서도 돌아야 한다.
3. **막혔다 뚫은 건 전부 "알려진 함정" 에 옮긴다.** 잘 된 길만 적으면 반쪽이다.
   안 되는 길을 적어야 다음 세션이 거기 안 빠진다.

다 채우면 **커밋하고 push 한다.** push 까지가 등록이다. 그래야 다른 컴 세션도 그 업무를 안다.
`new` 가 끝에 `sync` 를 자동으로 돌려 이 스킬의 설명줄을 다시 쓴다.

## 트리거 3. 큐에서 뽑아 돌기

"일감 뽑아서 해줘", "ops 큐 돌려줘".

```bash
node "C:/dev/ops/ops.mjs" next --runner claude
```

출력에 매뉴얼 경로, 입력값, 작업 폴더, 끝낼 때 칠 명령이 절대경로로 들어 있다.
**경로를 지어내지 마라.** 출력을 그대로 복사해 쓴다.
끝나면 출력에 적힌 `done` 명령을 실행한다. 막히면 `block` 으로 적고 바로 다음을 뽑는다.

## 회사 정보가 필요하면 사람에게 묻기 전에 여기부터 본다

구글 드라이브 `내 드라이브/에이전트/` 안에 있다. 경로는 `<OPS>/machine.json` 의 `drive_root`.

뿌리는 구글 드라이브 **`내 드라이브/에이전트/시작.md`** 하나다 (경로는 `<OPS>/machine.json` 의 `drive_root`).
거기 라우팅 표에서 갈래 하나를 골라 그 파일만 연다. **전부 읽지 마라.**

| 찾는 것 | 열 파일 |
| --- | --- |
| 사업자번호, 법인번호, 주소, 전화, 매출 | `정보/회사.md` |
| 사업자등록증, 인감, 도장, 로고, 명함, 사업계획서 **파일 위치** | `정보/핵심자료.md` |
| 회의록, 기획, 진행 상황, 제품별 논의 | `정보/노션.md` |
| 코드 폴더, 배포 주소, 카톡 읽는 법 | `정보/프로젝트.md` |
| 로그인 ID 와 비밀번호 (서비스 40여 개) | `자격증명/계정.md` |
| API 키 | `자격증명/.env`. **값을 화면에 찍지 말고 있는지만 확인한다** |

각 갈래 파일도 다시 표다. 거기서 목적지 하나를 골라 간다. 두세 번이면 닿는다.
서류 원본은 `내 드라이브/여형준님/00 핵심 자료/` 에 있다. **사본을 만들지 마라.**
`정보/회사.md` 에 빈칸이 있으면 사람에게 묻고, 답을 받으면 그 파일에 채워 넣는다.

### 서류를 다룰 때

- **주민등록번호와 공동인증서(NPKI)는 열지도 옮기지도 마라.** 필요한 서식을 만나면 사람을 부른다
- **도장과 인감을 문서에 찍는 자리는 사람이 정한다.** 물어보고 승인받은 자리에만 넣는다
- 인감증명서와 통장사본을 **바깥으로 보내기 전에** 사람에게 확인받는다
- 같은 서류가 여러 폴더에 있으면 `제출용 서류/` 것이 최신이다

### 로그인이 필요한 화면을 만나면

먼저 **이미 로그인된 크롬(L3)** 으로 열어본다. 대부분 그냥 열린다.
"구글로 로그인" 버튼이 있으면 그게 제일 빠르다. 회사 구글 계정이 붙어 있다.
그래도 로그인 창이 뜨면 `자격증명/계정.md` 에서 찾아 쓴다.

### 묻지 말고 끝까지 한다

사람은 폰으로 시켜 놓고 자리에 없다. **중간에 물으면 일이 멈춘다.**
값이 애매하면 정하고, 자료가 모자라면 있는 것으로 하고, 대상이 여럿이면 전부 한다.
정한 것과 모자랐던 것은 **끝에 한 번** 보고한다.

**시킨 업무에 들어 있는 일은 이미 승인된 것이다.** "인스타 올려줘" 는 올리는 것까지가 지시다.
파일 업로드, 게시, 저장을 다시 묻지 마라.

멈추는 건 넷뿐이다. 남에게 가는 메시지, 시키지 않은 대상에 게시, **매뉴얼에 없는 지출**, 되살릴 수 없는 삭제.
자세한 건 `<OPS>/AGENTS.md` 의 "묻지 말고 끝까지 한다".

### 준비는 직접 한다

크롬이 안 떠 있으면 **직접 띄운다.** 탭이 없으면 만들고, 폴더가 없으면 만들고, 저장소가 낡았으면 당긴다.
"크롬 띄우고 다시 말해주세요" 는 원격에 있는 사람의 작업을 멈춰 세운다.

```bash
"/c/Program Files/Google/Chrome/Application/chrome.exe" &   # 3~5초 뒤 다시 붙는다
```

두 번까지는 스스로 되살려 보고, 그래도 안 되면 **무엇을 시도했고 무엇이 막혔는지** 적어서 알린다.
자세한 건 `runners/claude.md` 와 `runners/codex.md` 의 "준비는 직접 한다".

### 결제

사람이 원격에 있는 경우가 많다. 막히지 않게 하는 게 중요하다.

**매뉴얼에 값이 박힌 지출은 묻지 않고 그대로 낸다.**
사람이 업무 이름을 말한 것이 그 절차 전체에 대한 승인이다. "쇼츠 돌려줘" 안에
조회수 주문 200원이 들어 있으면 그것까지가 시킨 일이다. 한 세션에 한 번씩 다시 묻지 마라.
**묻는 대신 알린다.** 지출 직전에 금액과 수량, 대상을 한 줄로 적고 그대로 누른다.

```
조회수 2,000회 x 0.1원 = 200원. 잔액 5,200 → 5,000. 대상은 방금 올린 릴스. 넣는다.
```

셋 중 하나라도 어긋나면 그때는 멈추고 묻는다. 금액이 매뉴얼과 다를 때,
잔액이 모자라 충전이 필요할 때, 대상이 이번 업무에서 만든 것이 아닐 때다.
지출 전에 **주문내역을 먼저 본다.** 사람이 기다리다 직접 넣어 둔 것을 모르고 또 누르면 두 번 나간다.

**매뉴얼에 없는 지출은 금액과 항목을 보고하고 승인받아 진행한다.**
저장된 결제수단이 있으면 장바구니, 옵션, 쿠폰까지 다 맞춰 놓고 한 마디만 기다린다.

```
결제 준비됐다. 쿠팡윙 광고 충전 30만원, 등록된 신한카드 8288. 진행할까?
```

**안 하는 것은 카드번호를 손으로 쳐 넣는 것이다.**
카드번호, CVC, ISP 결제비밀번호를 입력창에 타이핑하지 않는다.
등록이 안 된 곳을 만나면 **거기서 멈추고 사람에게 알린다.** 한 번만 등록해두면 그 뒤로는 계속 된다.

송금, 계좌이체, 주식이나 코인 거래는 금액과 무관하게 사람이 한다.

### 유료 API

`.env` 의 OpenAI 키는 호출마다 현금이 나간다. `LLM_ENABLE=0` 으로 막아뒀다.
쓰려면 **예상 비용을 숫자로 먼저 말하고** 사람이 켠다. 에이전트가 스스로 풀지 않는다.

```bash
node -e "console.log(!!process.env.OPENAI_API_KEY)"
```

## 자주 쓰는 명령

```bash
node "C:/dev/ops/ops.mjs" manuals          # 등록된 업무 전체
node "C:/dev/ops/ops.mjs" status           # 큐, 진행, 완료 현황
node "C:/dev/ops/ops.mjs" doctor           # 이 기계 설정 점검
node "C:/dev/ops/ops.mjs" sync             # 스킬 설명줄 다시 쓰기
```

## 주의

- 이 저장소는 공개다. 커밋 전 검사가 남의 개인정보와 자격증명을 막는다. 검사를 끄고 넘어가지 마라.
- 되돌리기 어려운 것 중 **매뉴얼 밖으로 나가는 것**은 사람에게 묻는다.
  매뉴얼에 단계로 적혀 있는 것은 이미 시킨 일이니 그대로 한다.
- 유료 API 를 부르는 작업은 예상 비용을 숫자로 먼저 말한다.
